# 灰燈寨 · 上部故事空間模型 / 第十版：場景檔案匯出與載入

使用 Chrome、Edge 等支援 WebGL 的瀏覽器開啟 `index.html`。Three.js 與資料已內嵌，可以離線使用。

左側上方「場景檔案」可隨時匯出或載入，不必先進入編輯。按「匯出場景檔」保存目前已完成的配置；日後開啟 `index.html`，按「載入場景檔」選取備份，就能接著編輯。

在一般檢視模式切換「單層檢視」，就會自動顯示途經該層、銜接上下樓層的梯段，不需要先點選樓梯或進入編輯。地下 B3、B2、B1，以及沒有配置房間的空樓層也能直接查看。

按「滑鼠建造」（沙盒編輯）直接進入目前房間所在樓層的俯視畫面。底部工具列提供「移動」、「畫通路」、「拆通路」；用滑鼠拖房間、連接牆面路口、調整道路轉折即可完成編輯，無需先填表。完成一次拖曳或連線就會保存；進階欄位保留為可展開的選項。

畫面中央從地下上行到頂部的主樓梯，可按工具列「主樓梯」，選好樓層後直接點地面放置。系統自動接到上一層，保留房間門口端點。從 B3 到 43F 的每一層都有可選梯段，包含途中沒有房間的樓層；每次放置只調整目前梯段。

初始配置沿用原圖的 26 個節點與 30 條連線。沙盒允許改變連線關係；編輯後的道路、樓梯與落層屬於自己的設計草稿，原文規格仍可作為參考。

## 故事空間修正

以下為隨附的初始配置理由。自行編輯後，房間的實際位置可能不同；自訂落層不代表原文指定樓層。

- 地下 P0、P1、P2 以短管線通道相接；P2 處理室暫靠 B3，出口爬梯跨越 B2、B1。原文只指定 B3–B1 上行段，沒有固定 P2 為 B1。
- R1 櫃檯後是 R2 舊麵店後廚，紅鐵梯從後廚梯口直接上接 R3 側門，不繞建築外緣或返回 R1。R3 宿舍、R4 洗衣廁所及 R5 工坊同層相鄰；R4b 是 R4 內的梯下神壇，不另造房間。
- R6–R11 沿住宅長巷與內井構成產線。R7 窄橋接 R8；R9 比 R8 低兩級，R10 是祈禱平台，R11 為錯層第三排工位。沒有新增 R7→R11 或 R8→R11 直連。
- R12–R16 構成修理、診療、貨梯與設備後勤群。R15 機房與 R16 伺服器室貼鄰，以短梯／防火門銜接，再從冷卻管下的維修夾層上行至 R17。
- R18 改為狹長消音走廊。R19 與 R20 共用同一片實體單向玻璃，由側門繞至墊高的觀察側，再往 R21。R22 保留釋放平台、下折避梁與向 43F 上行出口。
- 跨幕樓梯放在建築內的維修脊柱；R17→R14 誤導回路仍獨立保留。共用貨梯只呈現轉接井道，不新增乘梯跳層通路。

## 原文與配置提案

來源：[灰燈寨企劃庫](https://hanksonwu-design.github.io/dead-signal-docs/)，2026-09-23 讀取的節點圖與逐房規格。

初始配置直接沿用原文：26 個上部節點、30 條連線、方向、雙向條件、門禁／回訪規則、高度帶、房間用途與相鄰空間描述，以及 R17 的 32F。沙盒修改不會寫回原企劃網站。

本次提案：帶內具體落層、尺寸、方位、梯井位置、高差數值、內井封蓋標高與示意家具。原文沒有完整尺寸圖，這些不能當成已定案的建築圖。

## 用滑鼠完成編輯

1. 按「滑鼠建造」，在目前樓層的俯視畫面工作。
2. 「移動」：拖曳房間到新位置，拖四個角落控制點調整大小；放開即保存。選取房間後按「上移一層／下移一層」，可直接調整它的樓層；B1 上一層是 1F。
3. 「畫通路」：從房間四側的「＋」路口拖到另一間房間，終點會吸附到附近牆面；放開即建立通路。
4. 需要指定轉折時，改用點選方式：起點路口 → 空白處的轉折點 → 終點房間。點到終點後保存整條路線。
5. 「拆通路」：點選要移除的道路或樓梯；誤刪可立即復原。

拖曳房間與轉折點時，平面位置吸附到 0.5 單位格點。移動房間後，相連路口會跟著牆面移動，路線維持直角轉折。

### 直接移動樓梯

選取房間後，在右側「連接的樓梯」點選要調整的樓梯，也可以直接點模型中的樓梯。尚未逐層拆分時，拖曳畫面上的「✥ 移動樓梯」，可將整組梯段與中間平台一起平移；兩端房間的門口保持固定，門口到樓梯的平坦接近路段會重新銜接。

放開滑鼠即保存，按 `Esc` 可取消本次拖曳，完成後仍可復原／重做。若要改樓梯形狀，拖金色轉角；若要移動門口或改接房間，拖 A／B 端點。

### 編輯整棟主樓梯

1. 按工具列「主樓梯」，在右側「主樓梯 · 選擇樓層」挑選目前要放置的梯段。選單依 **B3 → B2 → B1 → 1F → 2F → … → 43F** 排列，共 45 個相鄰樓層區間，空樓層也可選取。
2. 移動滑鼠，在目前樓層的地面上預覽位置。按 `R` 或「旋轉 90°」調整樓梯方向；尚未點下之前只是預覽。
3. 點一下地面，放置目前梯段並自動銜接上一層。完成後保存並結束放置模式；仍保留選取的梯段。要重放可按「點地面放樓梯」，要處理其他樓層則切換樓層選單。

按 `Esc` 或取消操作可退出尚未完成的放置，不寫入變更。每次放置只修改目前選取的梯段，其他樓層不會跟著平移；既有房間位置與兩端門口保持，必要的接近路段會重新銜接。完成後可立即復原／重做。

需要指定轉角時，展開「微調形狀」，再拖金色控制點，或按「直梯／L 形／U 形」。微調預設收起，平常選樓層、點地面即可。

此入口整理既有主線的跨層樓梯及最後的出口梯，讓整棟主樓梯可逐層編輯。樓梯編輯保留房間現有位置與用途；43F 是上部出口門檻，沒有新增 R23 房間。這些梯段位置與形狀仍是自訂空間配置，不代表故事原文指定的建築尺寸。

單段放置、拖曳與形狀修改完成後即保存，可復原／重做，也會包含在匯出的配置 JSON 中。仍可由「滑鼠建造」處理房間、其他通路與分支樓梯。

### 每一層分開編輯樓梯

1. 其他跨樓層通路可先選取樓梯，再按右側「逐層設定樓梯」。途中每個樓層都會有可編輯的梯段，沒有配置房間的空樓層也包含在內；中央主樓梯可直接使用上一節的「主樓梯」入口。
2. 在「編輯梯段」選擇要調整的樓層區間，也可以用旁邊的前後箭頭切換。檢視切片以該段較低的樓層為準，例如編輯 8F → 9F，就看 8F 的切片。
3. 拖曳畫面上的「✥ 移動此層樓梯」，只平移目前梯段；每層可有自己的平面位置。
4. 展開「微調形狀」，拖金色控制點調整本段轉角，或按「直梯／L 形／U 形」改變本段形狀。不需要填寫座標或尺寸欄位。

底部樓層選單可前往空樓層查看樓梯。切換檢視樓層只改變畫面；拖曳、切換梯段形狀與「逐層設定樓梯」才會修改配置。空樓層的可編輯梯段是沙盒設計功能，不代表原文新增了房間、入口或可遊玩區域。

逐層設定、單段移動與單段形狀修改都會保存，並納入共同的復原／重做紀錄；匯出 JSON 時會一併保存各梯段配置。仍可用 `Esc` 取消尚未完成的拖曳。編輯後請檢查相鄰梯段的接點、平台與房間門口。

### 跨層連接

先在起點樓層點選路口，再用底部樓層切換控制前往目標樓層，最後點選目標房間。切換檢視樓層會保留尚未完成的起點與轉折；兩端有高度差時自動產生樓梯；跨樓層的新連線會直接建立逐層梯段。

底部「檢視樓層」只改變正在看的樓層；選取房間的上移／下移一層按鈕會真正更改房間配置。樓層高度壓縮與展開也僅供檢視。

### 修改現有道路

直接點選道路或樓梯，顯示它的控制標記：

- 拖曳轉折點，改變路徑形狀。
- 拖曳門口端點，沿牆調整位置，或改接其他房間。
- 使用路段中間的新增控制點標記，加入並調整轉折。

選取一般通路後，也可以直接按右側「直連／L 形／U 形」切換路線，或按「刪除通路」。已逐層設定的樓梯使用「編輯梯段」下方的「直梯／L 形／U 形」，作用於目前選取的梯段。

完成拖曳或直接操作就會保存，無需按「套用通路」。平面道路只沿 X／Z 軸前進，以直角轉彎；樓梯的高度沿路段上升或下降，轉彎處配置平台。

## 進階設定與檢視

左側「單層檢視」會同時顯示該層房間及途經的上下樓梯，包括地下層與無房間樓層。這是預設檢視行為；切換樓層只改變顯示範圍，不修改樓梯配置。要放置或調整樓梯時，再使用「主樓梯」或「滑鼠建造」。

需要精確數值時再展開進階設定：房間名稱、尺寸、位置與局部高差，以及通路寬度、單雙向、門口牆面、L 形／U 形樓梯、斜坡與各折點高度。進階欄位修改依面板的「套用修改」或「套用通路」按鈕保存；一般滑鼠操作不需要開啟這些表單。

離開編輯後可拖曳旋轉、滾輪縮放、右鍵平移；用「立體／正面／俯視」檢查空間，「透視」切換近大遠小效果。點 P／R 編號可查看故事原文與連線條件；上一間／下一間是編號導覽，不是強制通行路線。

自動路徑會嘗試沿端點房間外側繞行。過陡梯段、垂直落差或穿房警示出現時，調整路口、轉折或樓梯形狀；這些輔助檢查不等於完成全棟避障與碰撞驗收。

## 復原

房間、道路、樓梯與拆除操作共用「復原／重做」，依完成順序保留最多 50 步。「還原初始配置」恢復隨附房間與原始 30 條連線，還原本身也能復原。重新開啟頁面後保留配置，不保留這段操作歷史。

模型操作中的快捷鍵：

- `Esc`：取消尚未完成的樓梯放置、畫路或拖曳，不寫入修改。
- `R`：在樓梯放置預覽中旋轉 90°。
- `Ctrl+Z`／`⌘Z`：復原；加按 `Shift` 可重做。
- `Delete`：刪除目前選取的通路。

輸入欄位與匯入／匯出視窗開啟時，這些模型快捷鍵不會接管文字編輯。

## 保存、匯出與匯入

完成滑鼠操作或套用進階修改後，會自動保存至目前瀏覽器，也可以按「儲存配置」再次保存。正在繪製、尚未接到終點的路線不屬於已保存配置；請留意操作狀態訊息。

1. 在左側「場景檔案」按「匯出場景檔」，直接下載 `dead-signal-scene-YYYYMMDD-HHmmss.json`。檔名包含匯出日期與時間，方便保留不同版本。
2. 之後開啟這份模型的 `index.html`，按「載入場景檔」，選取先前保存的 `.json`，選好就會載入。
3. 繼續使用「滑鼠建造」或「主樓梯」編輯。若載錯版本，進入「滑鼠建造」按「復原」，即可撤回這次載入。

場景 JSON 保存全部已完成的配置：房間名稱、位置、樓層、尺寸與局部高差，完整道路連線、路口、方向、形狀與折點，以及各層樓梯。地下樓梯與 43F 出口通路也包含在內。尚未點下的樓梯放置預覽、尚未完成的畫路與未套用欄位不會被保存。

JSON 是場景資料；要重新觀看與編輯，需開啟本模型的 `index.html` 再載入。移到另一台電腦時，請同時保留模型資料夾與 JSON 備份。

- 下載受阻時，可進入「滑鼠建造」按「匯出場景 JSON」，在視窗按「下載 JSON」或「複製 JSON」，把內容另存為 `.json`。
- 也可以按「載入場景 JSON」，選擇檔案或貼上完整 JSON，再按「載入場景」。
- 本版相容舊版版本 1／版本 2 配置 JSON。版本 1 只有房間配置，載入時會套用房間並恢復原始 30 條連線與預設出口通路；不會沿用載入前的自訂通路。版本 2 保留其通路配置；舊檔缺少出口資料時使用預設出口。
- 載入前會驗證整份資料；有無效房間、重複通路代號或超出範圍的路線資料時，不會先寫入其中一部分。整次載入可以復原。

本機儲存依瀏覽器與開啟位置而定。移動 `index.html`、更換瀏覽器、改用其他網址或清除瀏覽器資料後，不一定能讀到先前保存的配置。請以匯出 JSON 作為可攜備份；本機保存不會直接覆寫 `index.html`，也不會自動修改原始碼。

本版使用本機儲存鍵 `dead-signal-building-sandbox-v2`；若尚無新版配置，啟動時會嘗試讀取舊版 `dead-signal-building-layout-v1`，把原有房間編輯遷移到新版。兩者皆只在相同瀏覽器與相同來源位置下可讀取。

## 編輯範圍

房間仍使用原有 26 個 P／R 節點，可自由改名、移動、改樓層與尺寸，不能新增或刪除房間代號。通路可新增、改接、刪除，總數上限 160 條；端點必須是兩個不同的既有房間。

沙盒可改變原圖的相鄰關係或通行方向，這些會作為自訂配置保存。初始故事連線與自訂路線需分別看待；不要把自己新增的捷徑解讀為原文既有動線。編輯後仍需目視檢查房間交疊、通路轉折、樓梯平台與端點銜接。

原文高度帶、原始房間用途與故事說明仍可在右側查看。使用者可另提配置，但編輯值不會變成故事原設定；例如把 R17 移到其他樓層，原文明定的 32F 仍是原文依據。

## 原始碼與驗證

`spatial.js` 管理初始配置、逐條通路與理由；`story-props.js` 管理家具、玻璃和地標；`model-source.js` 管理 Three.js 與操作；`editor-state.js` 管理房間與通路資料、版本相容、格式驗證和復原／重做；`sandbox-routes.js` 管理路口與直角路線幾何；`sandbox-ui.js` 管理進階道路編輯面板；`mouse-editor.js` 管理直接拖曳、畫路與拆除；`mouse-routes.js` 將滑鼠路徑轉成可保存的通路與編輯控制點；`floor-stairs.js` 管理逐層梯段、獨立位移、形狀與平台高度；`data.js`／`scene-data.json` 包含原圖與逐房原文快照。

修改時執行 `npm install`，編輯後執行 `npm run build`。僅查看現成 HTML 不必安裝。

原始配置的節點、連線、相鄰關係與故事空間檢查，只適用於隨附布局。任意編輯後的布局仍需重新檢查；保持直角轉折不代表路線一定沒有穿房或樓梯坡度一定合適。

此為故事空間灰盒與配置編輯器，不模擬遊戲解鎖或遊戲進度存檔；正式關卡仍需驗收鏡位、碰撞、導航與門禁。
