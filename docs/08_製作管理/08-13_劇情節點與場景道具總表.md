## 分類口徑

| 分類 | 本表的意思 | 不代表什麼 |
| --- | --- | --- |
| 主線 | 進房、離房、揭露或結局流程要求完成的來源／操作 | 不是要求把該房所有物件點完 |
| 擇一 | 多個合法來源或操作分支擇一即可 | 不是遺漏另一項就不能破關 |
| 選填 | 人物、文化、支線、差分或補充證據 | 不是隱藏主線門票 |
| 紀錄 | 已讀來源、推理筆記、資料索引或訊號索引 | 不等於拿走原件，也不等於可匯出影音 |
| 實物 | 劇本明定可翻動、拿取、放置、插入或移動的物件 | 不一律收入背包，不新增格狀物品欄 |
| 固定機關 | 門、閥、終端、拉桿、玻璃壓條等現場互動 | 不是可攜帶收藏品 |
| 環境物件 | 支撐生活、空間辨識與文化的可見細節 | 不自動發放證據或正確答案 |

「必需」以完整新遊戲流程為準；有效前情匯入、文字摘要、既有輔助模式依劇本承接，不能把選填回想自動補成已取得證據。以下物件以可辨識的敘事物件／機關組為單位，**不是最終美術資產 BOM**，不替未編號的每個碗、管件或紙張虛構資產數量。
