## 四個因果扣環

<a id="h-0103-63"></a>

### 一、她的失聯成為制度條件；封鎖是集團的選擇

```
內控人員失聯 + 敏感索引快取缺口
    ↓（符合 L-48 風險條件）
48 小時對帳
    ↓
康上報集團
    ↓（集團作出撤離與滅證決定）
鎖死出口、拋下所有人
    ↓
小花、阿尋、老周、阿彪 全數死亡
```

> 她逃離囚禁是求生權；這不會替她先前的長期簽核卸責，也不會把集團的決定轉嫁給她。
>
> **制度利用了她的失聯；真正把門焊死、把人留下的，是集團。**
>
> 她要為逃跑以前的管理、簽核、提價與當晚沒有取出硬碟負責；集團要為撤離、封鎖與死亡結果負責。兩者不能互相抵銷，也不能被簡化成「都是她害的」。

<a id="h-0103-83"></a>

### 二、門先封死，樓後來裂開

```
阿尋的 99% 封包（獨立來源）
    ↓（只有標頭抵達外部中繼端）
第5日留下歷史收件回執，未收到完整名冊
    （與下列破壞只具時間先後，並非觸發關係）
第2日集團封門 → 第6–7日樓體受創
    ↓（外部衝擊與脆弱結構連鎖斷裂）
局部樓層炸毀，核心區仍封死
    ↓
主角在下水道中毫不知情
    ↓
玩家探索殘痕與設備紀錄，重建封門、震損與尚可通行的路
```

> 對玩家而言，重點是：**裂開的牆沒有變成出口，求救離開過一部分，完整的人卻仍困在裡面。** 本機震損記錄只能支持破壞時序；是否有人收到後續求救、能否抵達，仍須各自的來源。
>
> 主角在下水道只聽見被管線和暴雨扭曲的低沉震動，沒有親見衝擊來源。T0 的探索用樓內日期、斷裂方向與封焊先後，逐步修正她對空間的認識；紅霧和蠶絲是現時感知，不能倒填到這些歷史紀錄裡。

<a id="h-0103-103"></a>

### 三、她選擇自己逃生

主角到達備份內門、停留十一秒，最後轉入 B3，沒有取出硬碟。行動不能反推她原本安排公開或救援；她承認那晚只想自己出去。早期照顧小花與後來核可傷害都是真的，求生不取消管理責任。

小花不知道她其後昏倒。小花於第七日晚死亡後，第二層回返自第八日起形成，晚於第六至七日的主要震損，不追溯造成 L-48 或最初死亡。

<a id="h-0103-109"></a>

### 四、兩週是受困時間

兩週由逃跑夜門端時間、封鎖與震損紀錄、P1 補給消耗及當下設備日期交叉建立。主角一直尋找出口，不曾安排十四天期限。記憶錯置發生在昏倒後把「想起身」體驗為「已重新撐起身體」。
