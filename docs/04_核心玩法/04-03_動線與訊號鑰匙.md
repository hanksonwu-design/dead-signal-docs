# 調查與設備操作

共用規則見[對應條款](../09_劇本/09-15_正式劇本_共用附錄.md#s-0003-2)。

怨靈即時辨識、潛行感知與劇情對峙沿用各自條件，不要求先收集探索線索。播放、資料回寫與權限操作在現場終端完成；筆記本不能發出聲音、解鎖設備或變成可上傳原件。

> 移動沿場所連通與殘留路徑，不是穿牆或瞬移。帶電門禁須供電與有效工作階段，純機械封閉仍須操作。節點圖記錄已走過的位置；主觀光標與窗外紅霧不充當現實搜救人員可見的路標。

定點場景不自由走動，但**房間之間的連接方式決定了調查的節奏與敘事的推進**。本作採「訊號解鎖」的非線性動線。

<a id="h-0403-14"></a>

## 移動：節點跳轉

玩家透過點擊畫面裡的門、樓梯、通道在房間之間跳轉。

一張「**疊樓節點圖**」（簡化的樓層連接圖，非寫實地圖）供玩家導航，顯示：
- 已探索
- 未探索
- 有未解訊號的房間
- 因集團封鎖或樓體震損而**斷裂的節點**（可看見、可聽見，但不可進入）

> 玩家可沿仍有效的雙向通路回訪；單向幕界、坍塌、鎖場及上下部分界不可逆行。新線索可改變可回訪房的理解；無法返回的房間仍可在筆記查閱已讀來源。

<a id="h-0403-26"></a>

### 震損後的斷裂動線

玩家逐層沿殘存踏板與側路上行。震損已切斷部分樓板、電梯井與消防梯；節點圖以裂口和灰色斷段標出阻隔，保留真實落腳點。主線仍透過貨梯轉接、包覆樓內的維修梯與 B1–B3 管線繞行，局部機構只恢復本段通行，不修好整棟樓。

完全塌毀的房間及封死外牆仍無法修復或進入；玩家沿各層尚能承重的側路找路，不把局部機關誤寫成修好整座樓。E-02 的外牆逃生梯與玩家的樓內維修步道是兩條不同路線，不能因到過 8F–14F 就自動取得舊檢修資料。

<a id="transition-rules"></a>
### 通路類型與逐層探路

宏觀仍是 **48 個導覽節點、56 條連線**，下分 **72 個次場景**：33 個探路次場景、25 個可查看過渡、14 個出口接景。八條操作路線為 T-R3-R5、T-R5-R6、T-R6-R7、T-R11-R12、T-R12-R14、T-R15-R16、T-R17-R18、T-R29-U4，另有十三條一般過渡。每段圖號、樓層、操作與鄰接順序見[次場景總表](../08_製作管理/08-13_劇情節點與場景道具總表.md#inventory-subscenes)。

**空間與文化：**住宅、小店與共用設施先存在，園區後加管制、配線與封板；一般住戶、語言及信仰不等於共犯或恐怖來源。完整公共梯與外牆逃生梯封毀，但承重維修步道、住戶夾道及部分設備外間仍可穿行。薄管、吊籃、晾衣繩不可踩踏或載人。正常通路不換門、不改樓層號、不重排物件。

**一般過渡：**非探路的十三條可查看通路仍可略過生活近看，從入鏡即可選出口，不新增機關、背包物品或資源費。回訪以已到過的同一通路短切鏡對位，也可重看。R13 ↔ R14 的安息門檻雙向有效；所有路線仍檢查原鎖場、追逐與封路。反向不是水平翻圖；踏步、門框及實際管件接續同時辨向。

<a id="ascent-route-contract"></a>
#### 逐層探路契約

**鏡位辨向：**逐圖交付來路輪廓、去路熱區、上行／下行／橫接方向及跨鏡延續的扶手或管件。反向不能直接把底圖水平翻轉；不提前啟動下一房聲音事件。探路圖另標封毀舊梯與可行側路，不能把所有可見門端都畫成可點出口。

**流程：**各節點先呈現來路、斷路與側路，再由玩家判讀支架、磨痕、管路或設備結構。點對方向或完成列明操作才開下一段，不以看完所有文字、等待秒數或新增證據解鎖。每層的唯一正式操作表位於所屬幕製作規格；圖號、樓層與前後相鄰節點由同一來源產生。各段不是連續樓梯動畫，也不加入隨機生成路線。

**物件與失敗：**所有必需零件在使用點同層可見、繫在設備上或有固定掛架，不向尚未抵達的房間借道具。操作先驗證安全到位，再開通出口；未到位可取消或復原，不消耗背包物品、訊號、體力與凝神穩定度。錯路有可見斷面／焊縫／支架證據，能退回上一個安全點，不靠反覆死亡試答案。生活物件選填；找路線索可原地重看。靜音及低動態仍可完成。

**節奏：**2F–15F 由 8F 工坊與 11F 網咖打斷長爬升；16F–22F 探路後在 23F 調查修理與診所，24F–26F 分流路到 27F 物流與供電，28F–30F 探路後進 31F 技術核心。33F–36F 探路後在 37F 完成校正遭遇，38F–39F 工作梯給出壓力退潮，40F 辦公調查後經 41F 到 42F 釋放。45F–50F 每層各有房間與短接景，不連續堆疊密碼。八條操作路線共 33 個操作鏡位、十三條一般過渡共 25 圖；鏡位數不是不同樓層數；原 47–66 分鐘估值已失效，章節及全劇時長均須按新房間分布灰盒重估，未核定。

**雙向回查：**R3 ↔ R5、R6 ↔ R7、R12 ↔ R14、R15 ↔ R16 可隨時退回本段已走過的平台及起點房；原房鎖場優先。全部局部操作完成且確實抵達對岸，才加入 `transition_seen`，再次通行可用已開路短切鏡或逐層查看。未抵達不開快速回查，不把「看過」當通行權限。原證據、回訪差分與 R4／R4b 支線仍在原房；改樓層不替玩家取得它們。

**單向幕界：**R5→R6、R11→R12、R17→R18 先驗原調查及門端條件，再由原「繼續」提交。取消不建進度；確認後只關起點房門，本段相鄰已到平台仍能往返查路，不恢復前幕。L-04 只走 R17→R14，不寫 C-02 的提交狀態。起行不寫入目的房到訪、電力、憑據使用成果或任何證據。

**保存：**使用 `transition_progress = { version: 4, route, from, to, view, committed }`，並保存各節點 `route_local.<圖號小寫>.open`、機關已到位狀態及最近安全落腳點。只接受上述二十一條正式路線、有效方向及其真正圖號；單向提交須與原章節紀錄一致。每次開通與切鏡原子保存；操作中讀檔回同層操作前安全狀態，已到位者保留，不能半開出口。先前通過節點的 open 必須構成連續前綴，不能只偽造最後一層。抵達後才將目的節點、到訪、transition_seen 與清除進度一次保存，目的房入場只播一次。

**舊檔與錯誤進度：**版本 1／2／3 的舊通路圖號改義，不按同名序號推定已走新路。已有目的房真實到訪的有效舊檔不追回補作；尚在舊轉場者沿經原章節驗證的提交狀態恢復至新路第一個安全平台。版本 4 損壞則回最近有效連續前綴的安全平台，最差回本段第一平台，不直接送到目的房；缺少可靠離幕紀錄則回原有效起點。不得只憑 to、committed 或一個圖號跳章。退回雙向起點可清除當前位置，但保留已完成的局部機關。

**驗收：**逐層測正向、允許的反向、錯路、取消、每次操作前後讀檔、零穩定度與輔助模式。原門檻未滿不可起行，局部障礙未處理不可進下一層，完成後重走不重解。測單向取消／提交、L-04 排除、錯誤序號、跳層存檔及版本 1／2／3 遷移；不能重發 K1-01／K2-01 或提前取得 R12／R18 的成果。地圖只記玩家已到節點，不提前揭露整段解法；文件流程圖則完整列出製作順序。

**重分層遷移：**版本 2 的 T-R11-R12 後段拆給 R12→R14 及 R15→R16，不能按同名序號或舊目的房到訪直接完成它們。每條新路獨立驗證原門檻、兩端真實到訪及必要劇情交易；例如供電未完成，不能初始化 R15→R16。未完成舊轉場回到經驗證新路的首安全平台，不跳過 23F／27F 房內操作。M1 保留原七窗各自觀察旗標，搬到 44F→45F 不新增看過紀錄；已抹除輪廓與不可逆供電選擇均保存。

**相容與錯路畫面：**有效舊檔已到過目的房，且原門檻／離幕紀錄可核實者，才將該路全部局部開通狀態、到位差分與 transition_seen 一起初始化；不重發證據。不符合者從新路首平台開始，不能只憑到訪欄位跳過驗證。錯路中的斷頭平台、封門與機腔都留在同一主圖可辨範圍，點擊進對應 C01 焦點近看後回原主圖，不偷偷新增未編號的可移動房間。

#### 拉閘門電梯與跨棟保存契約

**設備與供電：**L1 是 B 棟 29F／30F／31F 單人維修電梯；L2 是 B 棟 47F／48F 短程送物電梯，核定此架空設備容許主角單人乘行。它們是不同井道，均非 R14 的原物流貨梯，也不是 R30 固定維修籠。R15 三條供電路線均先保留這兩台的低速維修支路；部分供電後切換辦公室繼電器不切斷乘梯保留支路。備援採固定停靠的保留電量，不靠手機、安定點、感知或新增消耗品。供電未完成無法搭 L1，也不能由後方倒推取得電力。

**原門檻：**L1 沿 R15→R16，三路供電確認及 E2-06 仍必要；30F 踏板到位與啟用柄只開本梯 31F，不給 R16 憑證、第二層推理或 R17 權限。L2 沿 R29→U4，原必要查證、本地索引、責任收束完成才起行；未開或拒絕核可佇列仍可通行。無上部存檔依原合法下部起始契約提供已恢復的維修供電，不捏造上部供電選擇與證據。

**操作：**每次起行依序確認車廂平層、進入、關外閘、關內閘、選有效目的層。車廂或外閘缺一未鎖，上行鍵不動；到站後平層及實體門端驗證完成才可開閘。玩家自行開門與走出，不以影片結束自動寫目的房到訪。L1 首次只能 29→30，玩家出梯走到檢修箱，完成固定踏板及啟用柄後才開 30→31；無直達 29→31。完成後回訪可選 29／30／31，但僅在原章內門禁允許且所有必要局部操作完成時縮短動畫。L2 只可 47↔48。井道無額外可走層站、沒有可鑽電梯頂或控制台改樓層的出口。

**回訪與防卡關：**車廂唯一，記錄實際停靠層；已開路任一合法站可叫梯，空車先到站才解外閘，不生成兩台車。未完成 L1 30F 操作仍能回 29F；R17 假路是獨立下行維修通道，不誤接乘梯路。R30 不可逆提交當下即停用 L2 回程與已封區，不能等到沉降演出或制動後。正常斷電恢復不能讓玩家困在無解樓層。

**恐怖與資訊：**L1 首次 29→30 的拉閘倒影、L2 首次 47→48 的假停靠與內側刮擦各一次，只有玩家開始該段移動才可觸發。屬現時感知異常，不是新的動態歷史凝固、鏡像者登場、HA 扣罰或證據；不提供人名、不證實封口外有人。異常不改實體棟別牌、井壁樓層牌、平層刻線及落地踏面。假停靠只出現封板與鎖住的門扣，無死亡倒數或猜錯墜落。真實門鎖、到站、聲源與字幕分層，不能用聲音作唯一解題提示。回訪、讀檔不重播嚇點。L2 必須在 R29 責任收束完成、玩家主動上行後才開始，且在 U4 迴廊開始前結束。

**素材：**每台交候梯主圖、車廂主圖、抵達主圖及各自 C01 焦點。L1 兩段車廂共用同一底圖，圖號不同只表示時態及停靠段差分，不重複計獨立背景；兩端閘門各交開／閉／未扣，按鍵交不可用／可用／行進，井壁交各實體樓層牌。另交拉閘倒影、假停靠燈、鎖舌、平台踏面、刮擦聲字幕及低動態靜格；無頻閃，減少動態版與靜音版資訊等價。三組跨棟橋交雙端棟別牌、同層橋面與上下梯口，反向不翻圖；26F 分道圖可共用梁架材質，不能把四條有條件路畫成可自由串走的同一平台。

**狀態與讀檔：**新增局部狀態為 `lifts.l1.floor`（29／30／31）、`lifts.l1.upper_enabled`、`lifts.l2.floor`（47／48）、`lifts.<id>.anomaly_seen`、目前合法站及門扣。新進度使用 version: 4，保存棟別、實體樓層與真正圖號；L1 upper_enabled 必須與 30F 踏板／啟用柄及原供電交易一致。行進中讀檔回最近已確認安全停靠站，門與車廂同層，不繼承半開門；已開始的單次異常記為 seen，不用讀檔刷演出。動畫略過只結算有效的單段到站，不能跨過 30F 操作。

**版本 3 遷移：**T-R15-R16-03、T-R29-U4-01 等舊圖號已改義，不按同名、序號或 open 直接繼承。具原門檻、完整抵達交易與真實目的房到訪的有效舊檔，才初始化對應合法停靠與已完成機關；不補播異常、不重發證據。仍在轉場者回該路經驗證的首安全平台，保留原不可逆供電選擇；已有 R30 不可逆提交者不恢復 L2。其他未改義路段沿既有相容規則。

**驗收：**三種 R15 供電各測正向與回程，部分供電另測切換 R12 辦公室繼電器；L1 未扣門、未完成 30F、呼叫車廂、行進中讀檔及假停靠不可跳關。L2 測未開核可、拒絕、已核可、無上部存檔、R30 提交前後。三組橋逐一驗雙端棟別、圖號、反向與四分道門禁；共同驗 0 穩定、靜音、低動態、略過及舊檔遷移。上述是待遊戲實作的驗收規格，不等於已製作可玩的電梯。

## 解鎖：訊號門檻

疊樓不是一次全開放。往更深、更黑的樓層去，需要「**訊號鑰匙**」：

> 玩家必須先在當前區域解開足夠的謎題、拼出足夠的真相，才能取得進入下一層的條件（例如一個密碼、一段覆寫碼、一個必須先理解的因果）。

> **這讓調查的深入與真相的揭露同步：你理解得越多，樓就對你開放得越深。**

| 第五幕 → 第六幕 | **頂層覆寫碼** | F1–F4 是小花留下的人為記號；F5 是她由 C-12 發出 `VERIFY_ONLY` 後，R25 門端回傳的校驗尾碼。五段集齊，完成第四層揭露並處理 R26 阿彪對峙 |
| 第六幕 → 終幕 | R31 → R32 既有內門 | R31 必要鑑識、責任鎖定與解凍完成；選填姓名、買方頁與支線不擋路 |

<a id="h-0403-53"></a>

## 氛圍：限制如何讓恐怖變強

<a id="h-0403-55"></a>

### 被鎖定的視線

恐怖電影的鏡頭從不自由移動——它被導演鎖定，你只能看導演要你看的。

定點場景給了同樣的控制權：每一個構圖都是精心設計的，前景、陰影、畫面外的暗示，全部可控。

> **玩家無法「轉頭避開」不安的東西。**
> 當一個凝固瞬間的觀察者剪影正對著鏡頭（也就是正對著玩家），那種被凝視的壓迫感，是自由視角給不了的。

<a id="h-0403-64"></a>

### 畫面外的恐怖

定點畫面有明確的邊界，而**邊界之外是未知**。

聲音可以來自畫面外（隔壁房間的鍵盤聲、樓上的拖行聲、通道深處的呼吸），但玩家看不到源頭，也不能走過去看。

> 這種「**聲音在畫面外，而你被釘在原地**」的無力，是本作**噤聲者恐怖的主要載體**——你聽見它靠近，感知顯示它在門外，但你只能待在這個構圖裡。

<a id="h-0403-72"></a>

### 凝視的時間

> 自由探索的遊戲鼓勵玩家「快速通過」；**定點場景鼓勵玩家「停下來看」。**
>
> 因為每個房間是一張需要被解讀的畫面，玩家會長時間停留、放大、反覆觀察。
>
> 這種「**被迫凝視**」正是恐怖與愧疚的溫床——你沒辦法快速跑過一個暴行現場，你必須站在那裡，一個細節一個細節地看清楚它，然後理解你和它的關係。

<a id="h-0403-80"></a>

## 纏封與通路判定

四根觸鬚不建立四套門禁，也不增添通行物品；沿用 world.seal_state 的回返例外。前期不能由黑紋方向讀出正確路線。R32 解封後取消全部怨念回返，物理門鎖及坍塌仍按原條件判定；P1 是園區內的肉身回返目標，與跨越外部封鎖不同。

<a id="h-0403-84"></a>

## 怨念回返與正常動線

回返限指定對外門檻，不是隨機洗牌迷宮。P0 的實體路障保留；R17 的 32-S 外門後，L-04 物流維修支路實際回 R14，C-02 上行支路通 R18；錯誤路由只選錯既有支路，不是怨念回返，不列 R32 封鎖證據；R25 門邊另以既有感知鏡位呈現一次往外卻回到原處，不能截斷 F5 或主線進路。R32 提供可重現的出口節點作最終驗證。其餘房間與戰鬥撤離維持原方向。

每節點分開保存 physical_access 與 seal_return_target；後者只可指向該既有門檻內側，禁止跳到未解鎖房。封鎖解除只清除 seal_return_target，不改電力、憑證、洪水、坍塌或設備物件。F1–F5 仍供實體門端核驗，不能被「她願意開門」取代。
