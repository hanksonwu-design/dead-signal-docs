# 調查與設備操作

共用規則見[對應條款](../09_劇本/09-15_正式劇本_共用附錄.md#s-0003-2)。

怨靈即時辨識、潛行感知與劇情對峙沿用各自條件，不要求先收集探索線索。播放、資料回寫與權限操作在現場終端完成；筆記本不能發出聲音、解鎖設備或變成可上傳原件。

> 「先看清它怎麼靠近，再找出能讓它停下的方法。」
> 「知道它為什麼這樣做，不代表你必須原諒它。」

## 不砍血條

加入對戰橋段前，必須先確立一條鐵則，否則**戰鬥會摧毀整個遊戲**。

四條不可違背的原則見 [00-02_設計鐵則](../09_劇本/09-15_正式劇本_共用附錄.md#doc-0002)：

| # | 鐵則 |
| --- | --- |
| 一 | 怨靈有不同身分，受害不抵銷加害 |
| 二 | 主角永遠虛弱 |
| 三 | 戰鬥服務於恐怖與主題，不提供爽感 |
| 四 | 武器是理解，不是暴力 |

## 四種對戰，各司其職

四個模式組合成一套完整體系，**沒有一個是傳統的「砍血條」**：

| 模式 | 定位 | 文件 |
| --- | --- | --- |
| **訊號博弈** | 常規對戰。用現場通電設備播放既有正確訊號來應對逼近的怨靈——引開、安撫、重置。**武器是知識。** | [04-08](../09_劇本/09-15_正式劇本_共用附錄.md#doc-0408) |
| **潛行追逐** | 對應噤聲者（設定上無法溝通）。手無寸鐵的逃與藏，在定點節點間選擇路線避開它。**純恐怖高壓。** | [04-09](../09_劇本/09-15_正式劇本_共用附錄.md#doc-0409) |
| **凝固對峙** | Boss 戰。關鍵怨靈不能只靠播放訊號解除阻攔，須核對歷史與現時來源，完成各自的防禦及處置條件。**戰鬥即理解。** | [04-10](../09_劇本/09-15_正式劇本_共用附錄.md#doc-0410) |
| **權限反擊** | 使用內控主管權限強制抹除有效目標，留下不可恢復的空白訊號。依目標與處境呈現後果，不替所有使用情境作同一道德判決。 | [04-11](../09_劇本/09-15_正式劇本_共用附錄.md#doc-0411) |

上部另有遊蕩怨靈，屬環境應對，不另立第五種模式，見[環境應對：上部遊蕩怨靈](../09_劇本/09-15_正式劇本_共用附錄.md#upper-wanderer-response)。

## 依敵人分配

| 敵人類型 | 主要對戰模式 |
| --- | --- |
| **迴聲者** | 訊號博弈為主（重置循環）。最常見、最低壓，教學玩家對戰基礎。上部的 UA-R「點名的」是仍在巡房、點名的加害者迴聲者，改以躲藏應對，見下節。 |
| **呼喚者** | 訊號博弈（安撫／回應）。難度在於辨識它要聯繫誰——與收集解謎綁定。 |
| **噤聲者** | 潛行追逐為主。無法溝通，只能逃與藏。全遊戲最高壓段落。上部另有 UA-Q「離區噤聲者」沿運送死者的路線移動，見下節。 |
| **Boss 怨靈** | 凝固對峙。少數關鍵角色（如小花），理解之戰，情感頂點。 |
| **已配置的有效目標** | 權限反擊須符合現場供電、控制器與目標條件；角色身分不決定是否可用。後果依實際抹除記錄呈現，非敵意殘影不自動成為目標。 |

## 環境應對：上部遊蕩怨靈

上部另有 13 個遊蕩怨靈區（UA），把「受困與追擊」提前到上部前段；序幕兩區只教規則，不能抓人。它們不是對戰：與下部 UD 同列環境應對，不計入 14 段遭遇。UA 只沿媒介移動，不隨機遊走、不瞬移到她身後，也不開實體門；玩家靠方向字幕與非聲音前兆判讀，切斷媒介、關上門或持續往前即可脫身。

| 類型 | 它是什麼 | 怎麼應對 |
| --- | --- | --- |
| UA-S「拖鞋聲」 | 沿仍在運轉的水泵供水的濕路移動，永遠看不到腳踝以上 | 趁水泵嗡響時動作，停頓時靜止、屏息；走到乾燥或墊高處、關掉閥門，或穿過自閉門 |
| UA-R「點名的」 | 加害者迴聲者：宿舍／產線主管的殘留，沿讀卡器巡房、點名，察覺光與設備活動 | 光束經過時停止操作，留在暗處、布簾後或床鋪內；R8 樞紐可用有電的終端播 R1 叫號音引開。只出現在第一、二幕，權限反擊尚未解鎖，不能抹除 |
| UA-Q「離區噤聲者」 | 沿運送死者的軌道、升降梯與輸送帶移動，電力來自她自己的供電選擇；第四幕兩區沿用校正區噤聲者巡行 | 同噤聲者；R21 揭露後改為等候的凝視，不再追 |

被抓不造成外傷、不失去物品：恐慌 +1、每區最多 +3，回本區最近安全落腳點，再靠近時仍給完整前兆。遊魂靠近時有[接近干擾](../09_劇本/09-15_正式劇本_共用附錄.md#wanderer-interference)提示遠近；「遊蕩怨靈：標準／寬鬆／僅前兆」三檔都不影響證據、結局與成就。完整規則見 [UA 契約](../09_劇本/09-15_正式劇本_共用附錄.md#upper-wanderer-contract)。

## 節奏設計：分量偏少，每次都重

對戰在遊戲裡是「**少量黃金**」——不破壞收集解謎的主體。這意味著：

- 對戰**不頻繁出現**，而是在關鍵節點作為情緒高潮。大部分時間玩家在探索、感知、推理。
- 每一次對戰都有**敘事意義**——不是「刷怪」，而是遇見一個特定的、有故事的怨靈。
- 對戰與解謎**共用同一套知識**：玩家在解謎中理解怨靈，這份理解直接成為對戰的武器。**兩者是同一個引擎的兩面。**
- 上部遊蕩怨靈與 UD 同列環境應對，不算對戰，另依 UA 契約計數與限頻（[鐵則十五](../09_劇本/09-15_正式劇本_共用附錄.md#doc-0002)）：每區計一次高強度事件，與其他高強度事件合計每 10 分鐘最多一次；間隔未滿時該區延後啟動、不出現任何前兆，免得前兆後面沒有追擊。

<a id="h-0407-55"></a>

## 對戰與人物責任

玩家需要理解的是行為規律與可驗證的事實：怨靈在求助、控制誰、重複什麼命令，以及它的攻擊如何阻擋逃生。成功應對可以是回應求助，也可以是拒絕命令、破壞控制條件或撤離。

理解、同情、原諒與安息是不同的事。加害者可以被理解卻不被原諒，也不必有可安息的解法；受害者正在攻擊時，玩家仍可防禦。防禦成功不給善惡分數，抹除則保留其實際後果。

<a id="h-0407-61"></a>

## 纏樓顯形的攻防界線

具威脅怨靈依自身招式攻擊；被動怨靈保留原性質。阿尋複眼與節指、阿彪硬殼與鉤臂、小花四鬚與抱繭均接入固定場景防禦。小花於雙揭露後三拍防禦、再停戰進關係選擇；不用手機照射、筆記驅魔或點擊切斷觸鬚。招式契約見 04-12。

<a id="h-0407-65"></a>

## 對戰在愛情詐騙設定下的意義

話術產線的怨靈，常把工作與未完成的關係重播成恐怖。這一表現不涵蓋所有敵人；加害者也可能反覆執行命令、維持控制或掩蓋自己的行為。

> **話術產線的殘留常重播工作；控制者的殘留則可能繼續命令別人。**

| 舊理解 | 新理解 |
| --- | --- |
| 它在重演死前的痛苦 | 它在重演**它被逼著演了幾千小時的愛** |
| 你搞懂它是誰 | 你搞懂**它演的是誰、它在找誰**——而這兩者可能不同 |
| 回應一句話就替角色定性 | 適用的訊號遭遇可接續那句話，但真心仍不確定；控制型遭遇則依其規格阻斷或拒絕，不替它完成加害願望 |

<a id="h-0407-77"></a>

### 第五原則：鐵則二十八

> **你無法分辨一個怨靈重播的，是它演的，還是它真的。**

已寫入 [00-02 對戰五鐵則](../09_劇本/09-15_正式劇本_共用附錄.md#doc-0002)，與前四條同位階。

話術與親密表演殘留保留表演／真心歧義；控制、執行或掩罪型殘留則須讓線索解釋其行為與應對條件。每個角色各自成立，不要求共同的受害身世。

話術回應不由系統判定真心或腳本。已核實的同伴照顧與加害行動仍按來源呈現；這項歧義不否定小花曾真心照顧主角，也不抹掉可證明的責任。

## 靈異前兆如何接入對戰

氣氛事件與對戰使用不同判定：前者不攻擊、不扣資源；後者由既有遭遇控制器統一處理。HA-R18-01 是噤聲者既有前兆的表現，HA-R13-02 是 E-07 回應前的逼近，均不新增遭遇或另一套傷害。

新增氣氛必須在戰鬥開始時讓出畫面與聲音；不能用床簾差分蓋住真正攻擊前兆，不能在玩家看文件時偷偷進入攻擊。R11 主動攻擊仍沿用其 3 秒前兆與 6 秒空檔，潛行沿用至少 3.2 秒前兆；不把兩者合成一個通用秒數。命中、錯誤回應與重試全部沿用各自規則，同輪不得疊罰。

UA 區不是 HA，也不是 HP；HA 仍為 24 項。HA-P1-01 改作 UA-P1 的前兆，HP-01 兼作 UA-A1b 的前兆，兩者的編號與數量不變。UA 的追擊前兆同潛行至少 3.2 秒；接近干擾只用於 13 個上部遊蕩區，對戰、HA 與下部 UD 不套用。
