## 文件閱讀

角色與機制見各分類正文；場景連接及進行順序見關卡流程。製作交付與驗收集中於製作管理，文件不列修改沿革或已完成的討論項目。

## 製作範圍

全作 48 個導覽節點（上部 26、下部 22）、24 個靈異事件、兩場 Boss 與五種結局。節點包含共用子節點、獨立操作鏡位與片尾，不等於 48 間獨立房間或 48 張背景。文件描述設計要求，功能與素材的交付依製作與驗收清單確認。

## 現行敘事與玩法

主角肉身仍在泵房，探索為不自知的離體感知；終幕確認之後才選擇證據處置。規則見 [怨靈設定](01_世界觀/01-02_怨靈設定.md)、[結局系統](03_敘事結構/03-03_結局系統.md)。介面與玩法分鏡依所屬類型展示；正式遊戲資產、音效、動畫及 Godot 實作依製作規格交付。

## 小花關係與封鎖

目前主軸為真實友情、集團人為封鎖及小花死後的怨念回返；終幕先離體揭露、再封鎖核心揭露，最後以關係行動決定封鎖、資料及人物後果。詳見 [小花](02_角色/02-02_小花.md) 與 [終幕](06_關卡規格/06-08_終幕_頂層的地板.md)。
