# 灰燈寨 DEAD SIGNAL

2D 定點第一人稱、敘事恐怖解謎。繁體中文，PC 首發；內容上限為 18+。

**正式入口：[劇本總目錄](09_劇本/09-14_全劇本與關卡整合稿.md#book-start)。**

序幕至終幕各一份文件，每幕先放完整正文，再放該幕的空間動線、解謎條件、原件、狀態保存及圖像。跨幕設定只在共用附錄維護；總目錄不另存合併正文。其餘分類正文是自動產生的查閱副本，不各自維護另一套設定。
