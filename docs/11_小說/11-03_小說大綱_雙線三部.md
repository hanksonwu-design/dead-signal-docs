# 小說大綱　雙線三部

舊版大綱照遊戲的房間一章寫一房，戲都發生在開書以前，只能靠表單、名冊和錄音交代；第四幕她知道自己是誰以後，後面四幕都只是把同一個真相再加深一層。改版做三件事：

1. **小花自己說話。**小花線由小花用「我」對「妳」說她活著的日子，從押送車說到逃亡那一夜的 02:22。被騙、升職、簽字、背叛，都在讀者眼前發生。
2. **倒數從第一章開始。**地底檢修閘後面有一個人在呼吸，一次比一次慢。她以為是別人，要到樓上找人來開；第二十三章才知道那是自己。從那一刻起，往上走就是拿命去換。
3. **不照房間寫。**三十多個房間併成樂瑤線十八章，只留會改變她的地方。

本大綱管結構、章號與兩條線怎麼交會。全書句子另做過一輪順稿：句尾一個一個補上的形容（「白的，冷的」）、「很 X，很 Y」、「的那種」和「我不知道我怎麼知道」改成一個形容或她手上的動作，回返與刻意回聲的句子不動；四章樣板（第二、十五、二十二、二十七章）與鎖定句不動。第二輪逐章通讀，刪去替讀者問的問句（「他是誰？」「A-20、A-21 呢？」改成她去翻號牌）、段尾補一句解釋的話和幾處三連排比；視訊組那間房裡，樂瑤不再拿貼手機包膜來比，那是小花的比法。第三輪調節奏：小花線的開頭原本多半先報過了多久，視訊組的幾個月、平板、刻定位片這三段改從場面裡開始（第四章接第二章、第六章的二十九天、第十二章不說是哪一天的「那天以後」、第二十章接刻定位片那一段，這四處的時間語各有用處，留著）；第四、十六章的結尾不再停在「沒有」上；觀察室和工作梯上重複的動作刪去。第四輪打破一章換一條線的固定節奏：第八章「等」把樂瑤走進視訊組那間房，和小花在視訊組的幾個月切成十段交錯；第十七章「長痕與短痕」把觀察室的聲軌與玻璃，和小花在三號房刻定位片切成八段交錯。兩章都是謎題那一側先、小花那一側後，段與段之間只隔一條線，敘述不接；文字照原稿挪，只在第十七章窗台那一段的開頭加一句，把她接回觀察室。原第九章留下產線上面的第三排，原第十七章留下工作梯與二十九樓（第十八章），第十八、十九章因此連著兩章是樂瑤。第二十章小花坐在外門邊的那幾分鐘，切進三行中控紀錄，和第二十三章同一串字，敘述不解釋。樂瑤線每章的逐房細節、資料與伏筆，沿用[舊大綱：序幕至第四幕](11-01_小說大綱_序幕至第四幕.md)與[舊大綱：第五幕至終幕](11-02_小說大綱_第五幕至終幕.md)對應章節，兩份舊大綱改作樂瑤線逐房細綱；和本大綱衝突時，以本大綱為準。寫法見[寫作規範](11-00_小說寫作規範.md)，小花線另見規範第十一節。遊戲裡沒有的安排仍標「改編」；這次改版只動小說，遊戲劇本與規格不變。

## 兩條線與卷宗

**樂瑤線（現在）。**逃亡後第十四日（2025-11-18）起，她從地底往上走。寫法照舊：她知道多少，讀者就知道多少；她的敘述不寫自己的名字，她以為錯的地方照錯的寫。

**小花線（過去）。**從逃亡前十四個月的押送車，說到 2025-11-04 02:22 校正區的閂扣回去。小花只說她親眼看見的事，對「妳」說，但不叫名字；她不知道妳簽過哪些表，也不知道妳後來在下水道。小花線停在 02:22，之後她的位置交給卷宗。

**卷宗。**機器拍到、錄到的表世界，寫法照舊。逃亡那一夜的錄音散在各章章首；第二十二章「門後」與第三十章「新進說明」整章只有卷宗。

兩條線交替到第二十二章，中間打破三次：第八、十七章兩條線切在同一章裡，第十八、十九章連著兩章是樂瑤，第二十章小花那一夜切進三行機器的紀錄。小花線停了以後，第二十三章到第二十九章只剩她一個人往上走，讀者手上還帶著小花的聲音。

## 泵房的呼吸

序幕第二章那個用檢修閘鎖著、縫裡有很慢的聲音的凹室，從第一章起有了一台監視畫面（改編）。畫面裡是一個人蓋著毯子，膝上纏著布條，臉在畫面外；胸口起來，很久才落下。她以為是被困在地下的別人。

- **規則：**每一部她至少看到兩次那一格。只寫畫面裡看得到的東西，和她怎麼等那一口氣：等它起來的時候，她手上做了什麼、走了幾步、讀完了幾行。不寫倒數字樣，不寫她怎麼想。
- **走勢：**第一章起伏還算規律；第七章慢了；第十三章她在發電機房接回泵房那條維修線，呼吸穩了一陣，她以為替那個人爭到了時間；第十八章又慢下去；第二十三章她認出那個人；第二十四章她每被擊中一次，那個胸口就停幾秒；第二十七章一口氣要隔十一秒。
- **夢裡的機位：**第一章章首第四段卷宗（11/18，一個人撐著牆倒下）和這一格是同一個機位，敘述不接。

- **上部的起承轉合。**起是第一至三章：地底醒來，網後的樓梯是黑的；第三章立下目標，上三十二樓找康，叫人帶鑰匙下去開閘、把名冊報出去。承是第四至十三章：一路往上，第十三章康那裡落空，改成「我要找你們主管」。轉分兩次：讀者在第十四章先轉（小花看見妳拿著平板，聽見核可那一聲），她自己在第十八章轉（名冊影本上手寫的 Michelle）。合是第十九章：沒有人從外面來，主管那一套手勢她不用，用身體壓下釋放桿、賠掉右耳，網後的人走出去，她跨過門檻；結尾翻開筆記本最後一頁那條歪線，扣回第一、三章。她讀到自己名字的位置不往前挪，往前會對不上遊戲的 R21，第十九章「主管端已驗證」那一層也會失效。
- **上部最後一個畫面。**遊戲停在一張快要認出、還沒完全看清的臉；小說是她把拇指壓在照片的臉上，沒有拿開，照片要到第二十四章才清楚。

## 結局（改編）

遊戲裡外送和救援定位可以一起送出。小說改成只能送一樣：頂層對外的中繼就是阿尋那晚用的同一條線，它靠一座不穩的備援電力，只撐得住一次傳送。整包證據要用掉整段時間；救援定位只要幾秒，但先送它，證據就會停在九十九。她送出證據，裡面有她自己在責任人欄的名字，也有小花那張親筆申訴，一個字都沒改。救援定位沒有送出去。

小花在同一個螢幕上看見泵房那一格。她讓出一條縫，替她開了一道門；這道門和門牌迴廊一樣會把人送回去，只是這一次是送回地底。第二十九章她回到身體，沒有人知道她在那裡。她敲兩下管子，等，再敲兩下。很久以後，救援的人為了那份名單進到樓裡，有人照她的節奏敲回兩下。她沒有說原諒，小花也沒有。

## 第一部：往上（第一章至第九章）

九章已成初稿，見[第一部](11-21_小說_第一部.md)。樂瑤線由舊序幕至第二幕的成稿剪接併章；小花線第二、四、六章與第八章小花那一側新寫；第八章兩條線交切。

她以為：開頭，她從一個抓不住的夢裡醒來，不知道自己是誰，只知道要出去；地底檢修閘後面有一個人在呼吸，閘門打不開，往下的路塌了，她要上樓找人來開。結尾，她以為自己是被騙進產線、被逼著代聊的員工；她有了一個要找的人，小花，以為小花還在樓裡。地下那個人，她每看一次畫面就多等一下。

讀者多知道：小花和「妳」同一天、同一輛車進來；「妳」被送去內控培訓，搬去四十七樓，名牌上寫 Michelle。第一章黑暗裡那兩下、封底那個結、宿舍床縫的紙花，都是小花給的。

**第一章　地底**（樂瑤｜P0、P1）

沿用舊序幕第一、二章與成稿：四段夢裡的卷宗、醒來、倒抽的那口氣與水裡的手、裂開的膝傷、照片與「再等我一下」、管線層的生存痕跡、杯把上的拇指、祈願紙、換藥埋在泵嗡底下、拖鞋聲、鐵網上的濕手印。

新增（改編）：維修台旁一台蒙灰的檢修螢幕還亮著，分成四格，三格是黑的，一格對著泵和柱子之間那個凹室。她走到凹室前，檢修閘鎖著，縫裡只有那個很慢的聲音；她剛學會出聲的代價，沒有敲閘門。她在筆記寫下「地下　凹室　一人」，看著畫面等那個胸口起來，等的時候在膝上的布條又纏了一圈。往下的路塌了，往上的樓梯焊死；要開這道閘，要找樓上的人。

寫法：那一格她只看兩次就走。敘述不寫她覺得那條布條眼熟。

刪改：夢醒後的回想只留「一抓就散了」，不再把四段卷宗點一次名；刪去「誰會把垃圾疊得這麼整齊」「他回家了嗎」「八小時是多久」幾句替讀者問的話，聽聲、通道和泵房的描寫壓短，全章約七千七百字。第四輪：換藥的掀布和撕布各留一次，「嘶」仍落在泵停的那一點空裡；貼牆走留第一步的「啵」、工具箱那邊的「啪」、懸著的腳、暗一半的反光標和「沒有啪」，刪去中間重複的停與走；發光棒、柵門後的通道、祈願紙的膠帶壓短；刪去杯子後面「有人坐在這裡等水滴滿」和蛾「在哪裡看過這麼薄的翅膀」兩句替她指回去的話。水裡慢一拍的倒影保留，它是倒影升級的第一步（第三章留在原地，第十九章比她先敲）。全章約七千字。

**第二章　兩個字**（小花｜押送車與接收登記，逃亡前十四個月）

[成稿](11-21_小說_第一部.md)。押送車的帆布底下，看守的手機裂了一個角，保護貼下有一個氣泡；小花自己的手機在過關時被收走，電池早就鼓起來。把她叫來的阿蓮傳過一段語音：「這裡很好……妳也過來吧。」妳坐在她右邊，手腕擦過車斗的鐵邊，一直沒去碰它。車上發的表她只看得懂數字，「宿舍分配」在她眼裡是四個形狀；看守說過不准講話，妳湊到她耳邊說「住的地方」，在表格邊上寫了兩個字。車斗外有人敲了一下，看守抬頭看妳，妳的手指停在同一行，直到他低下頭。她替對面聽不懂中文的男生把「誰亂跑就打斷腿」翻成「不要走散」。大廳的燈箱下，電視裡另一個人照稿念著「這裡很好……你也過來吧」，停頓的長短和阿蓮一樣。白牆前閃光燈一亮，「這個上鏡。左邊。」妳被推到一本帳前面，不到一分鐘指出兩行日期對不上，「這個有用。送內控培訓。右邊。」她的表收進貼著 IN-06 的紙箱，邊上那兩個字也一起。燈箱上那四個字，沒有一個有屋頂。

寫法：敲回來的那兩下只寫聲音，不寫她怎麼想，也不寫是誰教他們的。
