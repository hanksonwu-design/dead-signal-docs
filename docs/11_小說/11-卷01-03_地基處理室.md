# 卷一　序幕：雨夜與地底

## 第三章　地基處理室

低管子後面的門開著一條縫。我側身擠進去，泵聲在背後斷了。

安靜得耳朵發脹。膝上的布一跳一跳的，跳得比剛才快。房間某個地方在滴水，只有這個聲音。

這裡幾乎全黑。對面高高的地方亮著一塊小牌子，綠的，「出口」兩個字，底下是一扇厚門。綠光只照到門的上半。

我貼著牆往裡走，腳下一空，踩進一道排水溝，溝從牆角斜斜地畫到房間中間。溝邊有個東西，我用鞋尖碰了一下，是一個搪瓷盆，翻倒著，盆底朝天。跟上一間那個杯子是同一種白嗎？太暗了，我看不出來。

房間中間有一張金屬椅。我推了一下椅背，椅子沒動，椅腳用螺絲鎖在地上。

椅面上有痕，一圈一圈的。我把手指放上去量，每一圈都一樣寬，兩根手指寬。椅腳上也有，也是兩根手指寬。椅背上有一排孔，孔邊的漆掉了，露出底下亮亮的鐵。

我把手縮回袖子裡。

椅子前面的地上有一道暗色的痕，從椅腳出發，拖得很長。我順著它走，走一步，看一步。它一路拖到那扇厚門底下。

門邊有一截袖子。

灰的，很長，長得蓋過手，垂在那裡。布料很輕地擦了一下，沙。

我眨了一下眼睛。沒有了。

我站在那道痕的中間，不敢往前，也不敢回頭。牆角高高的地方有一台攝影機，沒有亮燈。門邊還有一張矮桌，蓋著防水布，布角翹起來，露出一張黑白照片的一角，一個老人的肩膀。我一樣一樣看過去，就是不看門邊。

滴水聲停了。

下一滴沒有落下來。我等它，等了很久，它沒有落下來。

牆角開始有光爬上來，青綠色的，冷的，從地板的縫裡滲出來，漫過牆腳，一點一點往上爬。爬過的地方，牆就變了。

同一個房間。椅子、排水溝、門框，都在剛才的地方。可是天花板上的日光燈亮著，白得發青。我抬頭看，它沒有閃，也沒有聲音。

椅子旁邊有三個人。

離我最近的那個跪在地上，手伸出去要撿一張紙，指尖離紙還差一點點。他腳上是拖鞋，一隻掉了一半，掛在腳趾上。牆邊還有一個，扶著牆往下滑，滑到一半。第三個站在門邊，面向那扇門。

他們都沒有臉。臉的地方是平的。

我蹲下去，想看那張紙上寫什麼。紙是背面朝上的。我伸手去翻，指尖碰到紙邊，紙是硬的，硬得跟地板一樣，翻不動。我縮回手，指尖是冰的。

他們看得到我嗎？

跪著的那個，手還停在紙的上面。滑到一半的那個，還在一半。

有人在說話。只有一截：

「……不准離開……」

說完，又從頭說一次，一樣的口氣，斷在一樣的地方。是對誰說的？我找不到是誰在說。三個人的嘴，都在沒有臉的地方。

我發現自己站直了，背貼著牆，兩隻手垂在身體旁邊，好好地放著。我不知道我什麼時候站直的。

我的心跳得很重，撞在耳朵裡。

靠牆的那個人，手掌貼在牆上。指頭底下的牆面有幾道白白的刮痕，新的，粉還沒掉。

牆上那塊牌子，現在看得清楚了：

```text
房號　地基 07
```

地基，零七。我在心裡念了兩遍，怕它等一下又鏽回去。

翻倒的搪瓷盆，在這裡是正的，裝著半盆水。我湊過去。

水面映著燈管、天花板，和一個人。

那個人站在椅子和門的中間，離椅子兩步。沒有臉，胸前拿著一塊平平的板子，低著頭，在看那塊板子。板子的面是亮的，一小塊白光往上照，照到下巴該在的地方，那裡什麼都沒有。

我抬頭看椅子和門中間。那裡是空的。

我的手開始抖。我往後退，眼睛轉到門邊那個在等的人身上，又轉去看牆上的牌子，再轉回門邊。

門邊沒有人了。

跪著的那個、靠牆的那個，都還停在原來的樣子。只有門邊空了一塊。

房間裡只剩我的呼吸。

然後，從我看不到的地方，很輕的一聲。啪。拖鞋踩在地上。

我往後一縮，背撞到牆。

青綠色的光一下子退回地板的縫裡。燈管沒有了，三個人沒有了，只剩黑，和那塊綠色的出口牌。滴水聲回來了，一滴，落在翻倒的盆底上，咚。

剛才那個……是以前的事？

我去摸牆上那塊牌子。鏽得一個字都摸不出來。地基，零七。我還記得。

我走到剛才靠牆的那個人站的地方，就著出口牌的綠光，湊近去看。牆上有刮痕。很淺，幾道，被灰蓋住了，摸得到。剛才那幾道是白的。現在的是黑的。

先出去。

厚門旁邊也釘著一塊牌子，鐵的，比較新。我把它跟剛才那塊對，一個字一個字對：

```text
房號　地基 07
上行　大廳
```

同一個號碼，同一種排法。這條路通到大廳。

門沒有鎖。後面是一道鐵梯，很陡，一層轉一層往上。我扶著扶手爬。越往上，空氣越乾，鐵鏽的味道淡了，換成灰塵和一點油煙的味道。底下的滴水聲越來越小，到第二個轉角就聽不見了。

爬到第二個轉角，眼前黑了一下，我抓著扶手停住，膝蓋上新纏的布底下熱熱的，又滲出來了。等看得見，我再爬。腳下的鐵階一直在響，我放慢，它還是響。每一個轉角的牆上都有一扇門，都焊死了，焊疤一條一條鼓起來，還是亮的。

最上面是一扇門。只有我這一面裝著一根橫推桿。門邊釘著一塊舊牌子：

```text
單向通行
通過後自閉
```

門頂上有一個閉門器，門縫裡看得見斜斜的鐵舌。

我把手放在推桿上，沒有壓。

門的另一邊有聲音，嗡嗡的，很平，是日光燈。

我壓下去。

門開了一條縫，光從縫裡照到我的手背上，黃白色的，很便宜的那種光。我推開，走過去。

身後，閉門器把門慢慢帶回來。喀。鐵舌卡進門框。

我轉身。門的這一面是一整片平的鐵皮，沒有把手，沒有推桿。

我用手掌推。不動。我用肩膀頂，膝蓋一出力就痛，痛到眼前發白，門還是不動。我把指甲插進門和門框中間的縫，縫太細，指甲進不去，只刮下來一點漆，卡在指甲裡。

我把手伸進背包，摸到發光棒。三支。

我把手抽出來。

我拿出筆記本，翻到那一頁，在「不要出聲」下面寫：

> 不要出聲。
>
> 門關了就回不去。

字寫得很小。

我把筆記本收起來的時候，鐵皮的另一邊，樓梯上，啪。

拖鞋踩在鐵階上的聲音。

停了一下，又一聲。比剛才高一階。
