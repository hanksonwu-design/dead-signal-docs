# 第一部：往上

## 第二章　兩個字

看守的手機螢幕裂了一個角。

裂痕從左下角爬出來，三條，最長的那條快要碰到時間。他把手機橫著拿，看一段影片，看到笑出聲，笑完又滑回去重看。保護貼底下有一個氣泡，就在他大拇指旁邊，他每滑一次都壓過去，氣泡被推到另一邊，又自己跑回來。

我很想跟他說，那種貼要用卡片從中間往外刮，不能用手指。表姊的攤子上一張賣八十，幫貼另外加。

我自己的手機在過關的時候就被收走了。那支電池早就鼓起來，背蓋撐開一條縫，我本來打算到了這邊先換。拿走它的人要是把它塞在褲子口袋，大概會被燙一下。我想到這裡差一點笑出來，趕快把臉轉向帆布。

車斗用帆布蓋著，熱氣悶在裡面，聞得到機油，還有別人頭髮裡的汗。帆布上有一個破洞，車子轉彎的時候漏進一點光，從一排膝蓋上掃過去，再掃回來。

叫我來的是阿蓮。她在這邊做了半年，傳語音給我，說有一間修手機的店缺人，老闆會講華語，包吃包住，一個月寄回家的錢比表姊整個攤子賺得還多。她最後一段語音說：「這裡很好……妳也過來吧。」中間停了一下，我以為是訊號不好。那一段我聽了四遍，第四遍的時候，我已經在收行李了。

妳坐在我右邊。

我一開始沒有看妳，是先看到妳的手。妳把發下來的那張表平平壓在膝蓋上，用指甲按著，一行一行往下走，很慢，嘴唇在動，沒有聲音。妳看那張表的樣子，好像它欠妳錢。

妳的手腕內側有一道擦傷，紅的，邊上翻起一點皮。上車的時候有人在後面推了妳一把，妳的手擦過車斗的鐵邊，我聽到那一聲。妳一直沒有去碰它。

表是上車以後發的，看守從前面一張一張往後傳，一枝原子筆用繩子綁在板子上，大家輪流用。

上面的數字我看得懂。最上面一行有英文字母，NO. 後面空著。其他都是中文字，一格一格排好，跟我們攤子後面那面螺絲抽屜一樣滿。抽屜裡的螺絲我閉著眼睛都摸得出來，這一張我一格都不認得。

我認得的中文字不多。「人」，「大」，「口」，還有價錢牌上的「元」。其他的在我眼裡都是形狀。表的中間有一排四個：第一個頭上有一個屋頂；第二個頭上也是尖的；第三個上面分成兩半，往兩邊撇開；第四個左邊是一個小罐子。那一排後面空著一大格，比別的格子都大。

我不知道要寫什麼。前面有人寫了，有人沒寫。對面一個男生把筆咬在嘴裡，盯著那一格。

看守上車的時候說過：「不准講話。」他說得很平，眼睛沒有離開手機。

我用手肘碰了妳一下。

妳沒有馬上轉過來。妳先看前面，看守還在看他的影片，那個氣泡又跑回他拇指旁邊了。然後妳才把頭低下來一點，順著我的手指看。我指著那四個形狀。

妳把嘴湊到我耳朵旁邊，小到只剩下氣：「住的地方。」

說完妳就退回去，眼睛又回到妳自己那張表上。過了一下，妳把我手上那枝綁著繩子的筆拿過去，在我那張表的邊邊，那一排旁邊的空白，寫了兩個小小的字。妳寫字很快，最後一筆往外勾，勾出了格子。

我看那兩個字。第一個頭上有屋頂，跟那一排的第一個一樣。第二個的屋頂是尖的。

兩個字都有屋頂。我想，住的地方，屋頂多一個總是比較好。

這句話我跟著口水一起吞下去了。

車子在這時候跳了一下。帆布外面有人拿什麼東西敲了車斗，噹，一聲，就在妳背後那塊鐵板上。整個車斗的人都停住了。對面的男生把咬著的筆吐出來。看守抬起頭。

他看的是妳。

妳看著膝蓋上的表，手指按在其中一行，沒有往下移。我吞了一口口水，那一聲大得我自己都嚇到。看守的臉被手機照著，下巴那裡是藍的。

然後他低下頭，影片裡又有人在笑。

妳的手指往下移了一行。

過了一陣子，坐我對面的男生小聲問我一句話，用我們那邊的話。他聽不懂看守剛才在前面喊什麼。看守喊的是：「到了全部下車站好，誰亂跑就打斷腿。」

我跟他說：「他說到了要下車排隊，不要走散。」

他點點頭，把那枝筆傳給下一個人。

我也不知道我為什麼那樣翻。我只是覺得，斷腿那兩個字，他現在聽到也沒有用。

車停的時候天已經黑了。帆布一掀開，先進來的是燈。外面的燈很多，都是灰白的，照在每個人臉上，大家的嘴唇都沒有顏色。

那是一棟樓，上面疊著另一棟樓，再上面又疊一棟，窗戶大大小小，有的釘了鐵皮。我仰頭找最上面，找不到，脖子先痠了。

他們把我們趕進一個大廳。正對門口掛著一個燈箱，亮著四個字，比我們攤子的招牌亮很多。燈箱底下的架子上有一台電視，聲音開得很小。

電視裡只拍到一張嘴、一邊肩膀，兩隻手壓在桌上，指甲邊都是倒刺。那張嘴說：「我也是被騙來的。還要我騙朋友？」

畫面外面有一個男的聲音：「照稿念。錄完交給我。」

嘴角抬起來一點：「這裡很好……你也過來吧。」

「重來。笑。」

嘴角再抬高一點：「這裡很好……你也過來吧。」

「很好」後面那一下，停得跟阿蓮一樣長。

我把手伸進口袋，口袋是空的。我想打給阿蓮，問她錄那一段的時候，旁邊是不是也有人叫她重來。

電視又從第一句開始。

大廳中間擺了兩張桌子，一台筆電，一台相機，一面白牆。一個男的叫我們一個一個過去。輪到的人先把表交出去，桌邊的人把表收進一個紙箱，紙箱側面貼著一張貼紙，上面是英文字母和數字，我看得懂：IN-06。

我把表交出去。我那張被放在最上面，邊上那兩個字朝上，然後下一張蓋上來。

我站到白牆前面。閃光燈一亮，我眼睛裡留下一塊綠色的影子，很久都不散。拿相機的男人把螢幕拉近，用兩根手指把我的臉放大，又縮小。

「這個上鏡。」他說。

旁邊的人在筆電上打字。「左邊。」

我走到左邊。左邊站的都是年輕的，女生多，有兩個男生，臉都很乾淨。

輪到妳的時候，拿相機的人只看了一眼螢幕就搖頭。妳站在白牆前面，手腕那道擦傷在閃光底下很紅。另一個人從桌上拿起一本很厚的帳，翻開，推到妳面前：「看一下，哪裡不對。」

妳低下頭，手指又按著一行一行往下走，跟在車上一樣。我還沒想好要不要替妳擔心，妳的手就停了。

「這兩行日期對不上。」妳說，「這一欄加起來少了。」

妳講話的聲音比在車上大一點，還是很平。

拿帳的人把帳轉回去，看了很久。他回頭叫另一個人過來，那個人也看了很久。

「這個有用。」第二個人說，「送內控培訓。」

內控。我不知道那是什麼。我在心裡把那兩個音念了一遍，記起來，想說以後問妳。

「右邊。」

妳往右邊走。右邊只有妳一個。妳走過去的時候，手腕在褲子上擦了一下，擦掉一點血。妳沒有往我這邊看。我那時候想，妳大概是怕。

他們叫左邊的人往裡面走。我經過燈箱底下，抬頭看了一眼。

那四個字，我一個一個看過去，看它們頭上有沒有屋頂。

一個都沒有。
