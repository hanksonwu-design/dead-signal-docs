# 卷一　序幕：雨夜與地底

## 第二章　地底管線層

柵門後面是一段很短的通道，矮得我得彎著腰。肩膀擦著兩邊的管子，管子是溫的。前面什麼都看不見，我用手摸著牆往前，膝蓋每彎一次，布條就扯一下傷口。

然後通道放寬了，泵的聲音一下子近了很多。

這裡比下水道高，也比較乾。粗得抱不住的管子從牆裡穿出來，又鑽進另一面牆，管壁上全是水珠，一顆一顆往下爬，爬到底就滴下去。管子外面纏著一束一束的電線，有幾處綁著小小的方殼子。幾根混凝土柱子把這裡撐開，柱子中間塞著一台很大的泵，在響。光是從管子上的警示燈來的，橘紅色，隔很遠才一盞，照得到的地方都是橘的，照不到的就是黑的。柱子腳貼著反光標，一條一條亮著。

離我最近的那盞燈，燈罩裡面停著一隻小蛾，灰的，一動也不動。

我往前走，鞋尖踢到一個工具箱。它半泡在水裡，蓋子開著，扳手生了一層紅鏽。

工具箱旁邊有一疊撕開的包裝，都印著同一種藍色的標籤，裡面拆空了，每一個都摺好，邊對著邊，疊得整整齊齊。誰會把垃圾疊得這麼整齊？

再過去是一個急救袋，拉鍊開著，空的。柱子腳丟著一條布，硬了，捲成一團。

牆上有好幾條水位線，一條比一條高，深深淺淺的褐色，從牆的這一頭畫到那一頭。最下面那條在腳踝，最上面那條在膝蓋下面一點。

維修台上有一個搪瓷杯，白的，杯口掉了一塊瓷，露出底下的黑鐵。杯子擺在一根管子的接頭正下方，接頭在滴水，一滴，很久，又一滴。杯子裡有半杯水。

一個防水工作袋掛在維修台的角上，袋口用繩子綁著。

有人在這裡待過。維修的人吧，雨太大，躲下來等水退。看這些包裝，待了不只一天。

我把杯子拿起來。很輕，杯把上有一塊磨亮的地方，剛好是拇指放的位置。我的拇指放上去。

這杯子……我是不是用過？

杯子裡的水晃了一下。我把它放回去，放回接頭底下，杯底對準台面上那一圈水漬，對得剛好。

膝蓋一直在流。

我坐到柱子腳，把背包裡那捲醫療布拿出來。舊的布條黏在傷口上，我從邊邊開始掀，掀一點，停一下。布底下的皮被扯著，一絲一絲地跟著起來，掀開的地方一碰到空氣就發冷。我咬著袖子。傷口比我想的長，兩邊泡得發白、發脹，中間裂開的那一道是紅的，還在冒。我沒有看很久。

醫療布要撕。在這裡撕，聲音會很響。我把布捏在兩手中間，一點一點地扯，扯一點，停下來，再扯一點。泵在響，水在滴。沒有別的。

我把新的纏上去，纏得很緊，打了一個結。

換下來的那條，我丟到柱子腳。它滾了半圈，停在另一條旁邊。

管子的接縫上貼著一張紙。

紙摺成一個小小的方塊，用透明膠帶一圈一圈纏在接縫上，纏了很多圈，泡過水，膠帶底下的紙皺成一片。我湊過去，脖子上那幾道腫的地方一拉就痛。紙朝外的那一面寫著好幾種字，有的我看不懂，最下面一行是中文，筆畫很用力，被水暈開了：

```text
請讓他平安回家
```

他是誰？

我沒有把它撕下來。有人把它貼在不會被帶走的地方。

泵就在紙的後面。

它比我高，漆掉了一大半，露出來的鐵是褐的。它一直在響，低低的，嗡——停一下——嗡——，每一聲都比上一聲拖得長一點。泵和柱子中間有一道縫，縫後面凹進去一塊，用一扇檢修閘擋著，閘門上掛著鎖。我從閘門的格子往裡看，太黑了，什麼都看不到。

縫裡有聲音。很慢，很輕，夾在泵聲和水聲中間，進去，出來。

是泵在吸水吧。水被吸上去，又放下來。

我把臉從閘門上移開。

我站在柱子中間，想往哪裡走的時候，聽到有人在踩水。

很遠，很輕，啪、啪，拖著的，是穿拖鞋的人走路的聲音。我轉頭去找，找不到是哪一邊。聲音在柱子之間繞，在左邊的時候聽起來是右邊，在右邊的時候又到了後面。

我不動。

左邊那根粗管子後面，兩步。啪、啪。

停了。

右邊，一步。啪。

我看向右邊。柱子腳的反光標暗了一下，又亮回來。

右邊是樓梯，往上的。我差一點就跑過去。

樓梯口封著一片鐵網，從地上一直封到頂，四邊都焊死了，網上掛著一塊牌子：

```text
上行通道　封閉
```

我把手指勾在網上，往外拉了一下。網子嘩啦響了一聲，在柱子之間撞來撞去。我趕快放手。網後面的樓梯往上轉了一個彎，就看不見了。

左邊那根低管子後面，牆上釘著一塊門牌，字被水氣糊了一半，我湊得很近才看清：

```text
地基處理室
人員通道
```

貼著那張紙的，就是通往這裡的這根管子。

我摸到背包裡的發光棒。三支。我想留一支在這裡，折亮了放在工具箱旁邊，回來的時候還看得見。

我把它放回去。三支。我不知道還要走多遠。

我往左邊走，走到一半，背後的鐵網嗡地抖了一下。

只抖了一下，從右邊那個封死的樓梯口傳過來，是從另一邊被碰到的那種抖。

我停住。泵在響，水在滴，那個踩水的聲音不見了。

我等。網子沒有再抖。

我轉回去看。

鐵網上多了一個手印。濕的，手指併在一起，掌根壓得很深，在我的臉那麼高的地方。剛才沒有。水從手指那幾格一滴一滴往下掉，掉進底下的積水裡，一圈，一圈。

網後面的樓梯，還是黑的。
