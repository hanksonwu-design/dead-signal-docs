# 小說大綱　雙線上下部

舊版大綱照遊戲的房間一章寫一房，戲都發生在開書以前，只能靠表單、名冊和錄音交代；第四幕她知道自己是誰以後，後面四幕都只是把同一個真相再加深一層。改版做三件事：

1. **小花自己說話。**小花線由小花用「我」對「妳」說她活著的日子，從押送車說到逃亡那一夜的 02:22。被騙、升職、簽字、背叛，都在讀者眼前發生。
2. **倒數從第一章開始。**地底檢修閘後面有一個人在呼吸，一次比一次慢。她以為是別人，要到樓上找人來開；第二十三章才知道那是自己。從那一刻起，往上走就是拿命去換。
3. **不照房間寫。**三十多個房間併成樂瑤線十八章，只留會改變她的地方。

本大綱管結構、章號與兩條線怎麼交會。全書句子另做過一輪順稿：句尾一個一個補上的形容（「白的，冷的」）、「很 X，很 Y」、「的那種」和「我不知道我怎麼知道」改成一個形容或她手上的動作，回返與刻意回聲的句子不動；四章樣板（第二、十五、二十二、三十四章）與鎖定句不動。第二輪逐章通讀，刪去替讀者問的問句（「他是誰？」「A-20、A-21 呢？」改成她去翻號牌）、段尾補一句解釋的話和幾處三連排比；視訊組那間房裡，樂瑤不再拿貼手機包膜來比，那是小花的比法。第三輪調節奏：小花線的開頭原本多半先報過了多久，視訊組的幾個月、平板、刻定位片這三段改從場面裡開始（第四章接第二章、第六章的二十九天、第十二章不說是哪一天的「那天以後」、第二十章接刻定位片那一段，這四處的時間語各有用處，留著）；第四、十六章的結尾不再停在「沒有」上；觀察室和工作梯上重複的動作刪去。第四輪打破一章換一條線的固定節奏：第八章「等」把樂瑤走進視訊組那間房，和小花在視訊組的幾個月切成十段交錯；第十七章「長痕與短痕」把觀察室的聲軌與玻璃，和小花在三號房刻定位片切成八段交錯。兩章都是謎題那一側先、小花那一側後，段與段之間只隔一條線，敘述不接；文字照原稿挪，只在第十七章窗台那一段的開頭加一句，把她接回觀察室。原第九章留下產線上面的第三排，原第十七章留下工作梯與二十九樓（第十八章），第十八、十九章因此連著兩章是樂瑤。第二十章小花坐在外門邊的那幾分鐘，切進三行中控紀錄，和第二十三章同一串字，敘述不解釋。照房間寫的兩份舊大綱已移除：伏筆回收表照新章號併進本大綱（「伏筆回收」），舊的幕與章對到哪一章，見「舊章對照」。第五輪補下部篇幅：第二十四章之後加入兩章卷宗，第二十七章「AX-17」（阿尋那一夜的耳機收音）與第二十九章「撤離名單」（11/6 撤離與封樓），其後各章順延；第二十章補小花在三號房最後幾天聽出 C-12 的四個音、聽見自己「這一批」要被移交，今第三十五章補布蓋住凹室那一格與她念出門鎖紀錄，今第三十六章補她對著攝影機舉起手、第二下敲得很輕的那一次。第六輪再補下部：原「展示廊」一章拆成第二十八章「展示廊」與第三十章「燈具修理工場」，原「門牌迴廊」一章拆成第三十二章「簽核室」與第三十三章「門牌迴廊」，其後各章順延；第二十三、二十四、三十二、三十三章各以一段卷宗開章（11/7 康在中控看過收容室 3 那一格、11/8 阿彪在 C-07 等主管回應、11/12 康在簽核室送出交接、11/13 生活翼走廊的盡頭是一面磚牆），第二十九章補康在撤離以後送出「完成後留車，等我通知。」；樂瑤線各章多給她幾件自己動手的事（在 E-097 的標籤旁寫上林佩君、把四十一樓收件架的擋片推回去、把共鉗掛回空鉤），少一次正面攻擊，多幾處安靜的不對勁；第三十七章名冊多一行 0388 林佩君。第七輪補三條情節線，都取自遊戲下部的支線，改編進小說：第二十五章「未見」是卷宗，十月 P2-08 替 P2-11 代班、少了一份配給，P2-11 不見以後他先說「未見」，處置欄帶出「不交代位置，停止配給」和 IC-117，第二次問詢他說出夾層在哪裡；第二十六章「維修夾層」她爬過那個夾層；第三十一章「交易接洽室」是恒岳貿易的接洽處，IN-06-A 的醫療評估與移交單，遠端索引只准留一頁，她留下小花那一頁通報者註記；修理工那一條穿在第三十、三十三章：共鉗 07 的追責單背面是她寫的「非本人所寫」，47-10 門框裡夾著她當初替修理工寫的說明，她記起康要她寫在背面、在覆核表上圈了「留用」；第三十五章外送、第三十六章救援者那一疊與第三十七章名冊各接一處，第二十九章車次表上 M-001 的登車欄是空的。全書成為三十七章。第七輪修訂：小花在第二十六到三十三章之間不現身，只留下待過的證據，一章一種（夾層的掃痕、橋那一頭一句「妳要去哪裡？」、接洽處拉出來的椅子、47-01 的兩下、門框裡的粉），讓第三十三章她讀成報復、第三十五章「那我呢？」有來處；簽核室的管理覆核刪去，「留用」改由第三十三章的回憶帶出，帶她工號的文件少一份；第二十六、三十一章各加一次凹室那一格，補第二十四章到第三十四章之間的倒數；接洽處留下的那一頁在第三十五章接回外送，小花的申訴排在它下面。寫法見[寫作規範](11-00_小說寫作規範.md)，小花線另見規範第十一節。遊戲裡沒有的安排仍標「改編」；這次改版只動小說，遊戲劇本與規格不變。

## 兩條線與卷宗

**樂瑤線（現在）。**逃亡後第十四日（2025-11-18）起，她從地底往上走。寫法照舊：她知道多少，讀者就知道多少；她的敘述不寫自己的名字，她以為錯的地方照錯的寫。

**小花線（過去）。**從逃亡前十四個月的押送車，說到 2025-11-04 02:22 校正區的閂扣回去。小花只說她親眼看見的事，對「妳」說，但不叫名字；她不知道妳簽過哪些表，也不知道妳後來在下水道。小花線停在 02:22，之後她的位置交給卷宗。

**卷宗。**機器拍到、錄到的表世界，寫法照舊。逃亡那一夜的錄音散在各章章首；第二十二章「門後」、第二十五章「未見」、第二十七章「AX-17」、第二十九章「撤離名單」與第三十七章「新進說明」整章只有卷宗（「未見」「AX-17」「撤離名單」是改編）；第二十三、二十四、三十二、三十三章另以一段卷宗開章，寫撤離以後那幾天機器在那一層拍到什麼（改編，第六輪）。

兩條線交替到第二十二章，中間打破三次：第八、十七章兩條線切在同一章裡，第十八、十九章連著兩章是樂瑤，第二十章小花那一夜切進三行機器的紀錄。小花線停了以後，第二十三章到第三十六章是她一個人往上走，中間只有第二十五、二十七、二十九章三章卷宗切進來，把十月那兩次問詢、那一夜和撤離那一天別人的聲音放回她走過的樓層；四段章首卷宗把撤離以後的幾天，一天一天擺在她走到的那一層前面；讀者手上還帶著小花的聲音。

## 泵房的呼吸

地底那個用檢修閘鎖著、縫裡有很慢的聲音的凹室，從第一章起有了一台監視畫面（改編）。畫面裡是一個人蓋著毯子，膝上纏著布條，臉在畫面外；胸口起來，很久才落下。她以為是被困在地下的別人。

- **規則：**上部她至少看到四次那一格，下部至少兩次。只寫畫面裡看得到的東西，和她怎麼等那一口氣：等它起來的時候，她手上做了什麼、走了幾步、讀完了幾行。不寫倒數字樣，不寫她怎麼想。
- **走勢：**第一章起伏還算規律；第七章慢了；第十三章她在發電機房接回泵房那條維修線，呼吸穩了一陣，她以為替那個人爭到了時間；第十八章又慢下去；第二十三章她認出那個人；第二十四章她每被擊中一次，那個胸口就停幾秒；第二十六章她在維修脊柱的門禁面板上看到它，喘到自己平下來，毯子才淺淺起來一次；第三十一章眼淚糊掉那一格，起來的那一下她沒有看到，再等一次才看到，淺到要盯著毯子的邊；第三十四章一口氣要隔十一秒；第三十五章布蓋住那一格，她看不見它有沒有起來，外送完成後布自己捲回去；第三十六章她回到身體，第二下敲得很輕。
- **夢裡的機位：**第一章章首第四段卷宗（11/18，一個人撐著牆倒下）和這一格是同一個機位，敘述不接。

- **上部要有自己完成的事。**跟遊戲一樣，上部的成果是突破校正前段：第十八章她讀到自己的名字，第十九章親手開釋放梯、跨過門檻。全樓逃生和故事收束在下部。上部留下的是關係的疑問：「這次，等我一起走。」和往下走的腳步並在一起，誰丟下了誰，敘述不回答；不用「未完待續」收。
- **上部的起承轉合。**起是第一至三章：地底醒來，網後的樓梯是黑的；第三章立下目標，上三十二樓找康，叫人帶鑰匙下去開閘、把名冊報出去。承是第四至十三章：一路往上，第十三章康那裡落空，改成「我要找你們主管」。轉分兩次：讀者在第十四章先轉（小花看見妳拿著平板，聽見核可那一聲），她自己在第十八章轉（名冊影本上手寫的 Michelle）。合是第十九章：沒有人從外面來，主管那一套手勢她不用，用身體壓下釋放桿、賠掉右耳，網後的人走出去，她跨過門檻；結尾翻開筆記本最後一頁那條歪線，扣回第一、三章。她讀到自己名字的位置不往前挪，往前會對不上遊戲的 R21，第十九章「主管端已驗證」那一層也會失效。
- **上部最後一個畫面。**遊戲停在一張快要認出、還沒完全看清的臉；小說是她把拇指壓在照片的臉上，沒有拿開，照片要到第二十四章才清楚。
- **下部的開場。**遊戲下部先放逃亡夜的碎片；小說下部直接從小花那一夜開始（第二十章），接著第二十一章（R23）她把身上的傷一樣一樣看過，隔了一本書的讀者在這裡重新站好位置。

## 結局（改編）

遊戲裡外送和救援定位可以一起送出。小說改成只能送一樣：頂層對外的中繼就是阿尋那晚用的同一條線，它靠一座不穩的備援電力，只撐得住一次傳送。整包證據要用掉整段時間；救援定位只要幾秒，但先送它，證據就會停在九十九。她送出證據，裡面有她自己在責任人欄的名字，也有小花那張親筆申訴，一個字都沒改。救援定位沒有送出去。

小花在同一個螢幕上看見泵房那一格。她讓出一條縫，替她開了一道門；這道門和門牌迴廊一樣會把人送回去，只是這一次是送回地底。第三十六章她回到身體，沒有人知道她在那裡。她敲兩下管子，等，再敲兩下。很久以後，救援的人為了那份名單進到樓裡，有人照她的節奏敲回兩下。她沒有說原諒，小花也沒有。

**第一章　地底**（樂瑤｜P0、P1）

沿用舊序幕第一、二章與成稿：四段夢裡的卷宗、醒來、倒抽的那口氣與水裡的手、裂開的膝傷、照片與「再等我一下」、管線層的生存痕跡、杯把上的拇指、祈願紙、換藥埋在泵嗡底下、拖鞋聲、鐵網上的濕手印。

新增（改編）：維修台旁一台蒙灰的檢修螢幕還亮著，分成四格，三格是黑的，一格對著泵和柱子之間那個凹室。她走到凹室前，檢修閘鎖著，縫裡只有那個很慢的聲音；她剛學會出聲的代價，沒有敲閘門。她在筆記寫下「地下　凹室　一人」，看著畫面等那個胸口起來，等的時候在膝上的布條又纏了一圈。往下的路塌了，往上的樓梯焊死；要開這道閘，要找樓上的人。

寫法：那一格她只看兩次就走。敘述不寫她覺得那條布條眼熟。

新增（改編，第五輪）：硬碟插上、清單跳出來以後，狀態格出現以前，她打開收容室 3 的門鎖紀錄，從第一行念，念得很平，跟交接時念單子一樣：「十一月四日，兩點二十二分，兩次。」念到十一月九日那一行聲音卡了一下，從那一行開頭再念一次；念到「十一月十一日，二十三點四十七分，兩次。」，下面那幾行空的不念。左邊那一片布離她的臉一個手掌，她念的時候沒有退開，念完往她這邊靠了一點，碰到她的頭髮。這是她第一次回應那些敲門，用的是她自己的語言；敘述不寫她為什麼念，也不寫道歉。

新增（改編，第七輪）：排外送清單時，帳號關聯那一頁之後，她把 P2-08 的代班單和第二次問詢回執的歸檔排在一起，處置欄後面那一串沒有遮；共鉗 07 的追責單連背面那一行；接洽處那一頁不在硬碟裡，她在清單最底下補一行保存位置「接洽處終端，本機」，游標閃了很久，那一行自己接上「已連結，校驗相符」；最後一份仍是小花的申訴，接在那一頁下面。

**第三十六章　這張是我簽的**（樂瑤｜R33）

改編：她回到泵房的身體，衣料重新有重量，吸氣很費力；掌心沒有布，也沒有傷，膝上還是兩週前那條布條。沒有人知道她在這裡。她發不出聲音，抬起手，在管子上敲兩下，等；過了很久，再敲兩下。她一口水都沒喝。後來遠處有工具的聲音、人聲，有人在管子另一頭敲了幾下，她回兩下；那一頭停了一下，照她的節奏敲回兩下。燈照進來。救援者等她能簡短回應，拿出責任頁影本：簽核欄 Michelle，責任人欄梁樂瑤，兩個名字並排，和名冊上那一行一樣。她把手指停在簽名旁，不遮住一筆。「這張是我簽的。」

寫法：敲回來的那兩下只寫聲音，不寫她怎麼想，也不寫是誰教他們的。

新增（改編，第五輪）：第二次敲完、遠處的聲音來以前，加長那段等待：她看著頭頂攝影機那一點紅，知道三十四樓主管終端的待機畫面就是這一格（第二十三章她自己設的），舉起左手，掌心朝著鏡頭，撐到手肘自己彎下去；她睡著過，醒來杯子滿了，水流到她手邊，她沒有移開手，也沒有碰杯子；她再敲，「第二下很輕。」，照第二十二章 11/11 23:47 那一行原樣寫，不加說明。讀者在這裡和她一起不知道，她會不會停在小花停下的地方。

新增（改編，第七輪，遊戲 R33-A）：救援者翻那一疊紙時，她看到翻過去的幾頁的邊：一張代班單，工號那一格寫得很用力；一張追責單的背面，正中間一行往右邊倒的字。之後才是責任頁，照舊停在「這張是我簽的」。

**第三十七章　新進說明**（卷宗）

沿用舊終幕第四章：一份名冊，有人有名字，有人只有編號，C-07 仍是姓名未確認，阿彪仍在等待；小花的本名 Dara 在這裡出現，全書只有這一次；然後是逃亡後第十日樓內服務門，康死的那一刻，全書唯一攝影機拍不到卻寫出來的畫面。

新增（改編，第六輪）：名冊最上面多一行「0388　林佩君　未比對」，欄位間距照 0392 那一行。第二十八章她在標籤旁寫上的名字，到這裡還沒有人比對過；敘述不接。第七輪：AX-17 那一行底下多 P2-08「姓名未確認　未比對」與 P2-11「姓名未確認　下落待確認」，是她外送的代班單和問詢回執帶進來的。
