[製作規格](../10_製作規格/10-08_製作規格_終幕.md#node-r32-spec)

<!-- scene-image-r32:begin -->
**場景圖：R32-V01** · 頂層內井地板、小花、維修與責任終端、真實側牆、連續扶手及回返門框。

<a id="node-r32-access-script"></a>

**出入口：**
- **來路：備份內室短廊**：頂層地板來向的原門框，短廊承接 R31；扶手與真實側牆持續可辨。 單向承接轉身演出，不開放回上一幕探索。
- **回返門檻**：可見雙結與連續扶手的原門框，與沒有相接扶手的假門分開。 顯形完成後，在封鎖來源核對階段只試走一次並回同處；不在防禦中試走，也不通向新房。
- **離場／後果銜接**：沿原門框、翼膜與終端構圖呈現分支結果，不另長出出口。 完成揭露、防禦、結局選擇與分支演出後進人物後果；停攻不等於解封，留置分支也不因片尾開始就獲准離開。
- **封窗與假門**：內井封窗、翼膜及沒有連續扶手的門形。 不是露天屋頂出口；假門只在原攻防中辨認，不能切進不存在的房間。

**近看、原件與其他畫面：**
- R32-D01 P1 現時檢修鏡頭；R32-D02 倒下前後連續紀錄 E6-02；R32-F01 M6-01 自身最後靜格。
- R32-D09 肉身、連續位置與主觀移動核對；R32-C01 筆記、門框、祈願紙、雙結與廣播來源；R32-D03 指定回返門端原始紀錄。
- R32-C02 出口請求與收手位置；R32-V02 桌下低縫、門框退線、真實側牆凹位；R32-D04 五種行動預覽。
- R32-D05 責任原件、收件證明及定位；R32-D06 遮去自身責任的副本預覽；R32-C03 搭紙、讓位與鬆手。
- R32-C04 空椅與仍有呼吸的肉身來源；R32-C05 主管控制器與本地回返錨點。

#### [R32-00] 她沒有搶先回答

（鏡位切換）沿 R31 同一門框進灰暗核心，封窗、柱列、夾層與原控制器可辨。小花仍是熟悉人形，站在原門邊。

（靜態畫面／全景）視線沿原扶手走到側牆，斷鉚釘留在接縫旁；桌架低縫與門框退線也在同一空間。沒有遮住來路的翼，也沒有第二扇相似的門。

〔環境／背景聲〕低頻與細紙摩擦。

〔玩家〕先用 R31 已得維修索引核驗 P1 通道；四個小花來源熱點可見，但封鎖推理尚未啟用。不能先要求解小花才能讀肉身。

（靜態畫面／全景）控制器仍在玩家此側，冷備份原座在相連內室，通道與供電依 R15 恢復狀態核對，不憑主觀筆記突然多出網路。

#### [R32-01] 那是現在的時間

〔操作／介面點選〕在原維修終端開 P1 既有檢修鏡頭，確認通道、目前時間及連續影格。

（動畫演出）泵體後內凹室，白襯衫背側、膝部布結、背包在原位置。時間持續前進，至少兩次微弱可辨的呼吸。

〔玩家〕可放大、文字轉錄、低動態辨識，不用單張靜格判生命。完成查看才收 E6-01。

#### [R32-02] 起身以前與以後

〔操作／介面比對〕讀同一鏡頭在倒下前後的連續紀錄 E6-02，對時戳、泵體遮擋、包與身體的位置；明確是本次倒下至當下，不是宣稱連續昏迷十四日。

（介面呈現）來源頁分列「本地錄影」與「上層讀取通道恢復」，不把 R15 復電當第一格影像的時間。連續性與來源核驗都成立才收本件，不能由缺格推定沒有移動。

〔玩家〕兩週由逃亡與現時日期核對；其間受傷求生、休息與用補給不被推翻。

〔操作／感知觸發〕再查看 M6-01 自身最後靜格：手停在試著撐起的位置，包在泵體內側。

（靜態畫面／近景）記憶不動，沒有第二次歷史解凍。把「我準備起身」與開場感到「我已站起」的接縫放到同一頁。

〔玩家〕E6-01 是現時光學設備、E6-02 是連續設備紀錄、M6-01 是主觀記憶；來源不互相冒充，記憶不能外送成監控原件。

#### [R32-03] 我沒有走出去

〔操作／介面比對〕玩家親自核對肉身在 P1、倒下前後位置連續、自己的主觀移動接在時間空白之後。錯配免費退回，來源可重看。

（靜態畫面／近景）三項都成立後，當前主觀手與畫面上的膝部布結同構對照；不把這次知情做成一拳打來的跳嚇。

主角（知情後）「我沒有走出去。」

〔玩家〕三份來源親自核對後，她才確定自己仍活著。但知道肉身還在，不等於已經獲救；一路上的抹除、簽核與機械操作也沒有撤銷。

（靜態畫面／中景）小花留在門邊，不補「我早就告訴妳」或「妳一直躺在那裡」。

#### [R32-04] 哪一句是誰知道的

〔操作／介面點選＋物件近看〕玩家選「繼續核對小花與出口」，先看四個既有來源熱點，不把它們直接當全知往事。

| 原熱點 | 可讀／可聽範圍 | 不能推成 |
| --- | --- | --- |
| 同構校正門 | 小花經歷的等待與未完成承諾 | 她看過主角所有逃生動作 |
| 祈願卡 | 原祈願句與承諾來源；可與已讀 R20 對照 | 她知道硬碟後續處置 |
| 分來源廣播 | 警用紀錄與未送達求救各有來源 | 小花聽過警方全貌、警方聽見未送出封包 |
| 內門空位 | E5-04 支持主角當晚轉身下行 | 小花生前曾站在備份內門 |

〔玩家〕親查來源時顯示分類；祈願卡上的原句「請讓他平安回家。」及三秒承諾文字依原件無聲呈現。四點全讀後，再用固定順序六句卡選三句，錯卡退回、零成本。

（靜態畫面／特寫）祈願卡沿 [09-13](09-15_正式劇本_共用附錄.md#doc-0913) 呈現四個人為記號與空白第五格，F3 保留原定位痕。旁邊設備來源可回查 F5「09」，但紙上不補第五段；沒有再收集、再輸碼或自動開門。

〔玩家〕此卡是場所殘留的同構呈現，不是小花生前帶到頂層的實物，不能攜走或當監控物證。四記號只回收她曾留下什麼，不證明她知道後來的警方與硬碟去向。

〔條件〕已讀 R8 小帳約定者，可另展開已存宿舍文字「出去以後，不要假裝不認識我」，標示「先前觀察／個人筆記」。未讀不顯此附頁、不補收藏；這不是四熱點的第五個必讀點，不觸發主角反應或新配音。

| 句卡 | 可回查的依據 |
| --- | --- |
| 「她留下的是校正經歷，以及有人答應回來的等待。」 | 校正門與祈願卡；可支持 |
| 「內門前轉身下行，是承諾者當晚的行動。」 | E5-04 門端紀錄及已核身分；可支持 |
| 「警方後續與硬碟去向，不在她留下的這些片段裡。」 | 分來源廣播與空位；可支持 |
| 「內門的空位，證明她當晚也進過備份內室。」 | 空位不能證明小花在場；不支持 |
| 「攻堅廣播，是她親眼看過的事情。」 | 設備證據不是小花見聞；不支持 |
| 「那句承諾，證明當時已有帶走硬碟救人的計畫。」 | 承諾不證明後續計畫；不支持 |

〔系統／完成回饋〕（無聲，核對完成後）「來源範圍已核對」。

〔玩家〕結論只界定既存片段，不能因此判她現在毫無知覺；接著仍需 S6-01～03 現時核對。

（靜態畫面／全景）四物件保持同一構圖，來源標籤隨查閱補上，不改變物件本身。

#### [R32-05] 舊承諾不能再用一次（選填嘗試）

〔操作／介面點選〕玩家嘗試在此使用 #15。

〔系統／錯誤回饋〕（唯一無聲回應）「這裡無法播放這段訊號。」
不播放音檔、不重播主角承諾，不加小花反應或主角 OS。

〔玩家〕不扣成本、不進十秒擾亂，不要求試其他全部訊號；仍沿來源核對與關係行動繼續。這裡不是靠選一句對的錄音讓她消失。

#### [R32-06] 鎖開著，門卻不通（S6-01）

〔操作／介面查閱〕查 R31 必得索引中的指定回返門端原始紀錄，對鎖舌釋放與未抵外側的時間。

（介面呈現）設備只能證明鎖已開、外側通過未成立；旁邊另列玩家已有的回返觀察。沒有「怨氣濃度」或電腦診斷小花。

〔玩家〕只確認實體鎖不能完整解釋回返。R17 錯誤路由回 R14 明確排除，那是正常物流支路，不是封鎖證據。

#### [R32-07] 同一個門檻（S6-02）

〔前置〕離體已知、來源邊界已核對、尚未顯形或防禦。

〔操作／場景點擊〕點本房「前往出口」，原短轉場後回同一門框。

（靜態差分）門邊的雙結與兩下敲擊在相同位置重現。不是 U4 的單結被偷偷換成雙結，也不把正常室內移動都改成迷宮。

（鏡位切換）視線從重現的門框移回原扶手，仍接到同一處斷鉚釘。房間沒有換過；走不出去的，是剛才跨過的那道門檻。

〔玩家〕核對前後門框與局部顯現，確認一次現時回返；之後只回查記錄，不強迫再走十次。

#### [R32-08] 收起指向出口的手（S6-03）

〔操作／介面點選〕玩家選向出口提出離開請求，動作及台詞完成才觀察回返變化。

主角（現時試探）「我想出去。」

小花（現時回應）「別走」

（畫面特效）門框回返疊層增強。玩家再主動收手、停止催促，留在原安全位置。

〔玩家〕核對三處線索，才確認封鎖的核心。此時仍可收手；她沒有坐上空椅、承諾留下，也未操作設備或送出定位。封鎖仍在。

#### [R32-09] 先像庇護，後來沒有出口

〔前置〕雙揭露所需來源已核對；開始原二十至三十五秒現時顯形，非歷史影片。

（動畫演出）熟悉袖口向兩側延長，半翼先擋住高處壓下的陰影，灰粉在光束裡下沉。

（動畫演出）最初，柔軟翼緣只覆在上方，門框下沿仍留在眼前。翼緣收攏時，先遮去門框一側，再把可走的方向隔到薄膜後面；熟悉的袖口仍在她面前，出口卻已在另一邊。沿原顯形時長完成由遮護到封閉，不另插回憶。

（動畫演出）翼緣內收，肋側薄膜把門窗包進來。四根粗黑絨毛觸鬚以兩左兩右的不同走向跨內柱、纏窗框。

（動畫演出）翼膜近處的細纖維延續袖口邊緣，像那塊熟悉衣料被拉成了足以遮住整間房的幅面。靠近她的一側仍柔軟，貼住窗框的位置卻繃得透不過光。

〔環境／局部音效〕翼緣擦過時像有人替身旁的人攏好衣服；拉到柱角，摩擦變成乾澀的繃響。聲音沿眼前四根觸鬚與翼膜的接觸位置走，不從身後另起一個人聲。

（靜態畫面／全景）巨大不透明翼膜封住高窗，血紅透光映上內牆，極少光縫仍讓玩家辨向；小花的熟悉輪廓留在陰影中心。

（畫面特效）柱列沒有位移，卻一段段被翼影隔成近處的窄面；原本分屬桌邊、門側與高窗的視線，都被收攏到她面前。桌架低縫、退線與側牆接縫仍留在遮蔽邊緣。

〔環境／局部音效〕低頻摩擦接原回返門聲，不突升爆音；主角沒有被移到樓外仰望自己。

小花（現時）「妳每一次都說出去。那我呢？」

她沒有回答肉身、警方或硬碟，而是質問自己知道的承諾。等她說完、身形顯現，玩家才完整看清這一層封鎖。

〔玩家〕顯形無攻擊判定，提供低動態差分與來源回查。四根觸鬚不是四個開關，不開四段血條。

#### [R32-10] 先看見能退的地方

〔操作／視角切換〕安全觀察桌下低縫、門框退線、側牆斷鉚釘與連續扶手。各點有形狀與文字提示，不能只靠顏色或聲音。

（鏡位切換）玩家依次轉向三個原位置：低縫還容得下人，退線外仍有間距，扶手仍連著側牆凹位。翼影可以遮住遠處，沒有抹去剛才看過的接縫。

〔玩家〕準備完成，親自確認開始第一拍。每拍成功後停攻，自行轉到下一觀察位再確認；不自動把上一拍姿勢變成下一拍受擊原因。

#### [R32-11] 第一拍：低下去

（動畫演出）一根觸鬚投影壓進室內，灰粉劃出腰高掃線，桌架下低縫仍空著。

〔操作／場景點擊〕切到桌下低位。觸鬚擦過桌面，空隙仍通。

（靜態差分）桌面上方的光被掃線截斷，低縫另一端卻仍能看見原柱腳。玩家躲過的是這個高度，不是離開了她的範圍。

〔環境／局部音效〕灰粉的細擦沿腰高掃線掠過，低縫裡只剩被桌面隔住的悶響；觸鬚退回後，粉仍落在原光線裡。

〔玩家〕站在側牆仍躲不過掃線。避開後接續下一拍；失敗只重試這一拍，不必加快點擊補救整段。
