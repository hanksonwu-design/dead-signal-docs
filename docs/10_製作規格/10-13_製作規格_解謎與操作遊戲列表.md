# 解謎／操作遊戲列表

## 閱讀方式與幕別速覽

- <span class="collectible-required">橘紅色〔必要〕</span>：主線必須完成的查證、操作或遭遇。「擇一／所選方案內必要」只對當輪選定路線成立。
- <span class="collectible-functional">青綠色〔功能需要〕</span>：跨幕共用功能需要製作；玩家依原規則自行使用，不要求全部用過。
- 一般文字〔選填〕：支線、人物調查、環境觀察與可略過回報。〔條件〕會在同列寫明觸發條件，不能直接算成每輪必做。
- 「演出／片尾」另行標明，依原規格提供略過或等效摘要；必要資訊仍須完成原定閱讀或摘要確認。每列是一組有獨立判斷、操作或結果的玩法，多個近看與通路鏡位可合列，列數不代表獨立小遊戲數或遊玩時長。

上部為序幕至第四幕，下部為第五幕至終幕。以下依流程排列；可往返的房間與互斥分支保留原本彈性。

| 幕別 | 本幕主要在玩什麼 |
| --- | --- |
| [序幕｜雨夜與地底](#gameplay-act-0) | 查看痕跡、連起觀察、進入凝固查物，親手打開第一條上行路線。 |
| [第一幕｜門面與棚](#gameplay-act-1) | 用叫號改變阻路狀態，找人物碎片、組證據鏈，沿住戶與送衣通路操作機關。 |
| [第二幕｜產線](#gameplay-act-2) | 讀卡、比較名冊版本，判阿尋攻勢並重建最後一段校驗，再完成本幕推理。 |
| [第三幕｜技術核心](#gameplay-act-3) | 修線復電、核對照護與物流，選擇供電代價，依日期與原件接出正確路由。 |
| [第四幕｜校正區](#gameplay-act-4) | 看前兆避開威脅、辨認控制台規則，核對命令與本人聲音，以所選方式通過上部終局。 |
| [第五幕｜我也是被逼的](#gameplay-act-5) | 分清同人多版本與多人平行資料，重建七分鐘及門鎖紀錄，查阿彪來源並應對攻勢。 |
| [第六幕｜展示與暗巷](#gameplay-act-6) | 沿窗觀察人物、拆解三條偽名鏈，以移架、配管、吊運、遮光與燈位打開實體通路。 |
| [第七幕｜簽名與回返](#gameplay-act-7) | 比對簽勢與責任，選擇是否核可，測試同址回返，操作檢修旁路並封住兩側攻勢。 |
| [第八幕｜最後一道門](#gameplay-act-8) | 配平水箱、固定踏面，做五點空間與時序重建，手動制動，再核對身分及接回備份。 |
| [終幕｜頂層的地板](#gameplay-act-9) | 查證肉身與封鎖，依三種前兆換安全位，最後以一種具體行動決定關係與資料後果。 |
