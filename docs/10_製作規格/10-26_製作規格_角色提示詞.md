## 使用方式

- 每段 `asset` 區塊是一組定裝參考圖。生圖時把下方共用的【風格】與【不要出現】接在區塊後面，一起送出；【用途】不送進生圖，只說明這組圖給誰用、臉怎麼處理。
- 這些是製作內部的定裝照：給場景合成、凝固層剪影、影片參考圖與建模對造型用，不是遊戲裡直接出現的畫面，也不作宣傳圖、商店頁或角色卡。
- 【分圖】是同一組下的幾張圖，共用【內容】與光線，各自補一句不同處。生成時一次只送一句【分圖】，前面加「這張只畫」，緊接在【內容】後面送出。先生第一張分圖並定稿，其餘分圖拿它當參考圖，同一個人才會長得一樣。
- 人物要自然：像被請到牆前站好的普通人，不是模特兒。照設定寫的身高與體態生成，不拉長腿、不縮小臉、不修圖。
- 臉照[臉部使用層級](../09_劇本/09-15_正式劇本_共用附錄.md#h-0701-100)：只有梁樂瑤與小花的內部設定圖可有完整五官。梁樂瑤以[現行頭像](../../assets/07_視聽與介面/assets/角色設定_梁樂瑤_頭像_v17.png)為臉部基準、[三視圖](../../assets/07_視聽與介面/assets/角色設定_梁樂瑤_三視圖_v17.png)為全身比例與服裝基準；阿尋、老周、阿彪與康的臉靠低頭、側後、背光或反光自然遮掉，不交清晰肖像；小花在畫面上的臉只存在於「那張照片」的唯一臉稿，臉稿照[小花現行頭像](../../assets/07_視聽與介面/assets/角色設定_小花_頭像_v1.png)繪製，C-07 的正臉是美術方向的破例二，兩者都另行繪製，不用本表生成。
- 衣服照[隨機發衣系統](../09_劇本/09-15_正式劇本_共用附錄.md#h-0701-117)：上頭拿到什麼就發什麼，尺寸與款式不合、顏色低飽和，不是制服；只有梁樂瑤與康的衣服合身。
- 怨靈形體一樣照實拍質感寫：仍認得出原本的人、衣服與生活物件，異變只在設定寫明的部位。紅霧、白絲、冷青雜訊與翼膜紅光另成圖層，不畫進參考圖。

<a id="chp-style"></a>

共用，生圖時接在每段後面：

```asset
【風格】寫實、極致逼真的真人實拍照片質感：像劇組試裝時用普通相機拍下的定裝照，真人、真衣服、真實材質，不打戲劇燈、不調色、不修圖，白平衡照實。人物自然：是一個普通人被請到牆前站好或坐好，重心自然落在腳上，肩膀與手放鬆，沒有擺拍姿勢，表情平靜、沒有對鏡頭表演；身高、頭身比例與胖瘦照【內容】寫的真人比例。皮膚保留毛孔、細紋、膚色不均、乾燥與小瑕疵，不磨皮；頭髮有碎髮與真實髮流；手的五指比例正確，指節與指甲照實。衣服是穿舊、洗舊的真衣服：皺褶、起毛球、褪色、鬆掉的領口與不合身的肩線都照實，髒污只來自汗、水、灰塵與反覆清洗。背景是素面的中性灰牆與灰地，沒有道具與文字。真實相機與自然光學，50mm 到 85mm 平視、不變形，景深自然，帶一點相機雜訊。同一張圖裡有幾個視角時，是同一個人、同一套衣服、同一道光。不是電影劇照、不是時尚攝影、不是遊戲 CG、不是 3D 算圖、不是插畫。
【不要出現】模特兒式的擺拍、挑逗或英雄姿勢；拉長的腿、縮小的臉、過細的腰與幼態比例；磨皮、大眼、濃妝與修圖感（【內容】寫明的妝除外）；塑膠般光滑的皮膚與布料；全新、燙平、乾淨發亮的衣服；成套制服、臂章、名牌、公司標誌與可辨識的品牌；武器、護甲、戰術裝備與軍階標誌；國旗、國名與民族符號；提示詞沒寫到的飾品、刺青、傷疤與血跡；新鮮流血、傷口剖面與裸露；戲劇打光、輪廓光、光束、霧氣、暗角與刻意調色；太陽、陽光直射與陽光照出的光斑；遊戲 CG 感、3D 算圖感、插畫、動漫或卡通畫風；真實名人的長相；畫面上的任何文字、編號與浮水印。
```

## 梁樂瑤（5 組）

26 歲，164 公分。她穿著自己選的普通衣服逃跑，背著偷來的補給包，在下水道撐了兩週。造型來源：[造型設計設定](../09_劇本/09-15_正式劇本_共用附錄.md#h-0201-44)。

<a id="chp-ly-t0"></a>

#### CH-LY-T0 梁樂瑤・現在

```asset
【素材】角色｜梁樂瑤・現在｜CH-LY-T0
【內容】一位 26 歲的成年女性，身高 164 公分，體態消瘦。黑色直髮約到肩，用沒有裝飾的髮圈綁成低馬尾，髮束略鬆，有少量碎髮，髮根帶一點油濕。完全素顏，嘴唇偏乾，眼下有淡淡的黑眼圈。穿一件普通的白色長袖襯衫，不是制服剪裁，袖口隨手捲到前臂；襯衫有局部撕裂、水漬與乾掉的泥，髒污只到中等程度，仍看得出是白襯衫。寬鬆褪色的牛仔褲在膝部、褲腳與口袋邊磨破，左膝的破口裡露出一條草率纏住的舊布，布上只有乾掉的暗色血跡。髒白色的休閒鞋浸過水、沾著泥灰。背著一只灰色的舊帆布軍用野戰背包，包體偏扁、沾泥，幾乎是空的。臉與前臂有零散的表淺擦傷；頸側有幾處彼此分開、正在淡掉的不規則瘀痕。手背與指節乾裂，指甲短、邊緣不齊。她站著，肩線平，手肘靠近身體，疲倦但站得穩。
【構圖】16:9 橫幅，全身入鏡，鏡頭在胸口高度平視，人物腳下留一點地面。
【光線色調】陰天的窗光從左前方斜進來，柔和均勻，沒有硬影；白襯衫保留布紋不過曝，牛仔褲與背包的暗處仍看得出磨損與縫線；整體低飽和，膚色照實。
【分圖】正面、側面、背面三個站姿並排在同一張圖裡，背面看得見整只背包與低馬尾。
【分圖】不背背包的正面與背面兩個站姿並排，看得出襯衫背後的水漬與肩帶壓出的皺痕。
【分圖】她彎下一邊膝蓋、一手撐著大腿正要站起來的側面，看得見左膝的布條與鞋底磨薄的邊。
【用途】內部設定用。場景合成、鏡像者與反光人影都照這一組；鏡像者完全沿用同一套衣服、傷勢與背包，不另做分身。
```

#### CH-LY-HEAD 梁樂瑤・現在的頭部

```asset
【素材】角色｜梁樂瑤・現在的頭部｜CH-LY-HEAD
【內容】同一位 26 歲成年女性的頭部與肩膀。小而自然的橢圓臉，面頰保留自然的寬度，下顎柔順、下巴俐落但不尖；深棕色的杏眼，睫毛偏長但是原生的樣子，眉毛平直自然，鼻樑高度適中、鼻尖柔和。完全素顏：看得見毛孔、淡淡的雀斑、不均勻的膚色與乾燥的嘴唇，眼下有兩週睡不好留下的淡黑眼圈。額角與顴骨有零散的表淺擦傷；頸側有幾處彼此分開、正在淡掉的不規則瘀痕。黑色直髮綁成低馬尾，額前與耳邊有少量碎髮。白襯衫的領口有水漬與乾泥，肩上壓著灰色的帆布背包肩帶。表情平靜、疲倦，嘴自然閉著，沒有哭也沒有笑。
【構圖】16:9 橫幅，胸上景，鏡頭與眼睛同高平視，約 85mm。
【光線色調】陰天的窗光從左前方斜進來，柔和均勻；臉上沒有硬影、沒有眼神光加強，暗面仍看得出皮膚紋理；整體低飽和，膚色照實。
【分圖】正面、四分之三側面、正側面三個角度並排在同一張圖裡。
【分圖】正面一張，視線看著鏡頭稍下方，嘴唇自然閉著。
【用途】內部設定用，以現行頭像為臉部基準。這張臉只供 R31 的重合鏡位合成，不另作遊戲內肖像、人物卡或宣傳圖。
```

三十上下，176 公分。一個受困者的舊衣服外面，又被套上另一件工作外層；壓迫感來自他堵住路，不來自體型。造型來源：[造型設計設定](../09_劇本/09-15_正式劇本_共用附錄.md#h-0204-23)、[服從的硬殼](../09_劇本/09-15_正式劇本_共用附錄.md#h-0204-238)。

<a id="chp-ab-alive"></a>

#### CH-AB-ALIVE 阿彪・生前

```asset
【素材】角色｜阿彪・生前｜CH-AB-ALIVE
【內容】一位三十歲上下的男性，身高 176 公分，肩背較寬，但肌肉並不誇張，是做過粗活的普通體格。短髮是自己推剪的，後頸的髮際不齊；沒有刀疤，沒有鬍鬚。最裡面穿一件洗舊的灰藍色條紋 Polo 衫，領口留著一道耳機壓出的摺痕；外面套一件別人穿過的深土褐色工裝外套，左右兩個口袋款式不同，右肘有一塊灰線縫的補丁。右腰夾著一枚可以拆下的門禁扣。深色工作褲的後口袋裡塞著一副折起的灰色工作手套，露出一截。鞋是和其他人同款的舊運動鞋，只是鞋底較厚、鞋頭磨損得重。他站著，頭頸微微前傾，膝蓋留著一點隨時能動的彎度，雙手低垂、手掌鬆開沒有握拳，像在等人開口。他低著頭，額頭的陰影蓋住眼睛，只看得見普通、疲憊的下半張臉。
【構圖】16:9 橫幅，全身入鏡，鏡頭在胸口高度平視，人物腳下留一點地面。
【光線色調】陰天的窗光從左前方斜進來，柔和均勻，沒有硬影；土褐外套的暗處仍看得出補丁與口袋的縫線；整體低飽和，膚色照實。
【分圖】正面、側面、背面三個站姿並排在同一張圖裡，背面看得見後口袋的手套與不齊的後頸髮際。
【分圖】腰部以上的側面一張，看得清 Polo 衫領口的摺痕、兩個不同款的口袋與右肘的補丁。
【分圖】右腰門禁扣與垂著的右手的近照一張，手掌鬆開。
【用途】凝固層剪影與資料影像照這一組。不配武器；不做巨漢、屠夫、蒙面或軍靴。
```

#### CH-AB-SHELL 阿彪・硬殼形體

```asset
【素材】角色｜阿彪・硬殼形體｜CH-AB-SHELL
【內容】同一位 176 公分的男性人形，站在一道窄窄的素面門框裡，堵住整個門洞。衣服像兩層尺寸不合的乾硬外殼，套在同一個身體上：外層是深土褐的工裝外套，肩線被窄框頂得翹起；內層灰藍條紋的領口仍然整齊；右腰的門禁扣卡在兩層之間。胸腹向內摺成一個沒有任何器官細節的黑腔，腰身窄得幾乎只剩一道縫。兩邊的肘關節各分成兩段，反向折回來，手掌卻平平整整地停在蓋章或等待核可的姿勢。殼面是鈍的黑，不反光，只有受壓的折線吃到一點光。整個輪廓是被塞進過窄欄位的工作服，不是戰士的鎧甲。頭低著，臉被門框的陰影遮掉。
【構圖】16:9 橫幅，全身入鏡，鏡頭在胸口高度平視，與他隔著兩三步的距離；門框在畫面中央，人形佔滿門洞。
【光線色調】頭頂一支老舊的日光燈，偏青綠，只照到肩線與殼面的折線；胸腹的黑腔與門後一片暗，仍看得出外套的布紋與兩層領口；沒有其他光源。
【分圖】正面與側面兩個站姿並排，側面看得見胸腹往內摺的空腔與窄成一道縫的腰。
【分圖】一邊手臂的近照一張，肘關節分兩段反折回來，手掌平整地朝下。
【分圖】雙肩往上抬、兩層外殼擠緊的正面一張，雙手仍垂在身側。
【用途】第五幕查證間的現時形體。不加武器或新的狂暴階段；凝固裡的他仍是生前那個靜止的人。
```

## C-07（1 組）

二十出頭，160 公分。姓名與族裔沒有揭露，造型不暗示答案。造型來源：[C-07 造型設計設定](../09_劇本/09-15_正式劇本_共用附錄.md#h-0204-124)。

<a id="chp-c07-body"></a>

#### CH-C07 C-07・身形與衣著

```asset
【素材】角色｜C-07・身形與衣著｜CH-C07
【內容】一位二十出頭的成年女性，身高 160 公分，中等體型，普通人的樣子。短髮長到下巴與頸側之間，像很久沒有好好修剪，左邊別到耳後、右邊自然垂下。穿一件褪色的淡紫色棉質襯衫，肩線略窄，最上面的扣子仍然扣好；下身是深色工作褲，腳上是舊便鞋。衣服完整，沒有撕破。她坐在一張普通的金屬摺椅上，背挺著、沒有靠椅背，雙手放在大腿上，手指沒有握緊。她的臉朝向畫面外，從這個角度只看得見耳朵、臉頰的邊線與別到耳後的頭髮。
【構圖】16:9 橫幅，坐姿全身入鏡，鏡頭在坐著的肩膀高度平視。
【光線色調】陰天的窗光從左前方斜進來，柔和均勻，沒有硬影；淡紫襯衫保留布紋不過曝，深色工作褲的暗處仍看得出皺褶；整體低飽和，膚色照實。
【分圖】坐姿的四分之三側後、正側面、背面三個角度並排在同一張圖裡，臉都朝向畫面外。
【分圖】站姿的側面與背面兩個角度並排，雙手垂在身側。
【用途】第五幕查證間凝固人像的身形與衣著。她完整的正臉是美術方向的破例二，只存在於那一個固定構圖，另行繪製，不用本表生成，也不裁成角色卡。
```

## 康（1 組）

外觀四十到五十歲，175 公分。把他單獨放進任何一間普通辦公室，沒有人會回頭看第二眼。造型來源：[造型設計設定](../09_劇本/09-15_正式劇本_共用附錄.md#h-0205-26)。

<a id="chp-kang-office"></a>

#### CH-KANG 康・普通主管

```asset
【素材】角色｜康・普通主管｜CH-KANG
【內容】一位外觀四十到五十歲的男性，身高 175 公分，中等身材，腰腹有久坐的人常見的一點鬆。短髮梳得整齊，鬢角有少量灰白，戴一副極細的深色框眼鏡。穿一件合身的暖灰色棉質襯衫，袖口扣好，沒有領帶、沒有西裝外套；下身是深灰色長褲、普通的黑色皮帶與便鞋。襯衫的胸前口袋內側夾著一張白色無字的卡片，只露出一道邊。一手拿著一只霧面的不鏽鋼杯，另一手夾著一個透明文件夾，文件夾裡是空白的紙，上面壓著一支沒有品牌的原子筆。他站得很穩，不佔地方，像在走廊上等會議室空出來。他低頭看著手裡的文件夾，鏡片上一片反光蓋住了眼睛，表情只是在聽、在確認。
【構圖】16:9 橫幅，全身入鏡，鏡頭在胸口高度平視，人物腳下留一點地面。
【光線色調】陰天的窗光從左前方斜進來，柔和均勻，沒有硬影；暖灰襯衫保留布紋，鏡片只有一片灰白的反光；整體低飽和，膚色照實。
【分圖】正面、側面、背面三個站姿並排在同一張圖裡，正面低著頭、鏡片反光。
【分圖】他坐在一張普通的會議椅上的側面，不鏽鋼杯放在素面的桌上，他正翻開透明文件夾。
【分圖】胸前與雙手的近照一張，口袋裡露出一道邊的白色卡片、不鏽鋼杯與文件夾都在焦內。
【用途】監控、錄影與資料媒介裡的影像，以及片尾那一個過去敘事鏡頭，都照這一組。不做黑西裝、紅領帶、金戒指與邪笑；第一眼要先被讀成普通主管。
```
