# 影片導演註記

> 本頁是各幕影片製作列表的手寫來源。劇本描述決定畫面裡發生什麼，導演註記決定怎麼拍、怎麼聽；註記不新增劇情、操作或素材需求，兩者不一致時以劇本為準。改完請執行 `node tools/build-video-list.mjs`，註記會併進對應段落的提示詞，取代自動整理的分鏡、鏡頭與聲音。

## 共用鏡頭語言

- **現在：**第一人稱主觀視線以約 28mm 為基準，接近人眼視角。鏡頭固定，或只由她的身體帶動（撐起、低頭、轉頭），動作有重量、有停頓，地平線保持水平。
- **夢境：**約 35mm、大光圈淺景深。焦點可以在遠近之間轉移；鏡頭只極慢推近或停住。
- **主觀記憶：**約 35mm，從她當時的眼睛看出去，幾乎不動，只有極輕微的呼吸起伏。用焦點轉移代替運鏡，不推、不搖。
- **光：**只寫畫面裡真的存在的光源，寫清楚光從哪裡來、照到什麼、怎麼變。
- **聲音與後製：**音效、台詞、字幕與合成文字都對到秒；台詞與字幕照劇本原文。全作沒有配樂。

## 怎麼寫一段註記

- **標題：**段落編號加一個短名。**對應描述**抄劇本描述裡的一小段原文；劇本改寫後對不上，產生程式會停下來提醒重新核對。
- **情緒節奏、鏡頭、光：**各寫一到兩句。首尾要對齊另一張主圖時加寫**尾格**。
- **表格：**每列一個時間段，從 0 秒接到剪用長度。「畫面」只寫攝影機拍得到的東西；「聲音與後製」寫這個時段的對點，沒有就寫「—」。

### P0-00·1　聊天視窗

- **對應描述：**黑裡亮起一個聊天視窗
- **情緒節奏：**深夜一個人的疲倦，打字時藏著一點期待，送出後等不到回覆。安靜、慢，停在「但」的那一下是全段的呼吸點。
- **鏡頭：**約 35mm、大光圈淺景深，正對一塊懸在黑裡的螢幕光面；鏡頭不推不搖，只有極慢、幾乎察覺不到的漂浮感。光面邊緣失焦，融進黑裡。不出現鍵盤或任何人的手。
- **光：**唯一光源是螢幕略偏冷的白光，只照亮光面前一小團空氣與浮塵，四周全黑；結尾亮度一路降到全黑。

| 秒 | 畫面 | 聲音與後製 |
| --- | --- | --- |
| 0–1.5 | 全黑。畫面中央慢慢亮起一塊失焦的白色光面，像螢幕從休眠醒來；焦點在 1 秒內收清，光面邊緣仍融在黑裡。光面上只有柔和的空白，視窗介面與字後製合成。 | 風扇低低的轉聲先進，整段不斷。 |
| 1.5–3.5 | 光面停穩。前方空氣裡幾粒浮塵在白光裡慢慢飄，畫面其他地方不動。 | 輸入框的字從 1.5 秒起一個一個出來，打到「但」停 0.6 秒再打完。這段只有風扇聲，打字聲與提示音留給下一個黑場。 |
| 3.5–4.5 | 送出的瞬間光面微微一亮，再回到原本的亮度；之後畫面完全靜止，像在等。 | 3.6 秒：送出的訊息出現在視窗裡；對方的名稱與頭像保持空白。 |
| 4.5–6 | 光面從邊緣開始慢慢暗下去，一路降到全黑；浮塵最後才消失。 | 風扇聲留到最後，接下一個黑場。 |

### P0-00·2　一隻灰蛾

- **對應描述：**一隻普通灰蛾緩慢擦過視線
- **情緒節奏：**空無、半睡半醒。第一個活的東西輕輕擦過，近得讓人一縮，又馬上離開。
- **鏡頭：**約 35mm、大光圈，焦點固定在約一臂遠的黑暗裡；鏡頭不動。蛾離鏡頭太近，大半在焦外。
- **光：**幾乎全黑，只有一層看不出來源的暖灰微光，剛好勾出蛾翅的邊緣。黑裡帶細微的底片顆粒，不是死平的純黑。

| 秒 | 畫面 | 聲音與後製 |
| --- | --- | --- |
| 0–1 | 全黑，只有細微的顆粒在動。 | 微弱的呼吸，很近，像是自己的。 |
| 1–3 | 一隻普通灰蛾從畫面左側極近處緩慢飛過，大半失焦，翅緣薄得像紙片、透出一點微光，帶過一道模糊的灰影。 | 乾紙般的翅翼摩擦聲跟著蛾由左向右掠過。 |
| 3–4 | 蛾從右側出畫，黑裡只剩顆粒。 | 摩擦聲在右側遠去，留下呼吸。 |

### P0-00·3　趨光

- **對應描述：**針孔般的暖光出現
- **情緒節奏：**被吸引，像被叫住。好看，但越看越不安。
- **鏡頭：**約 35mm，鏡頭極慢向前推近，6 秒只推近約一成，不晃動。焦點先在近處零星的蛾，1.5 秒起轉到遠處的亮點。
- **光：**唯一光源是畫面深處一個針孔般的暖光，接近鎢絲燈色。逆光把每隻蛾的翅緣勾成細細的亮邊，蛾身是剪影；亮點周圍有一點自然的光暈，其餘全黑。

| 秒 | 畫面 | 聲音與後製 |
| --- | --- | --- |
| 0–1.5 | 黑暗深處亮起一個針孔大的暖光點，先是失焦的一小團，再慢慢收成一點。 | 摩擦聲還只是零星幾下。 |
| 1.5–4 | 灰蛾一隻接一隻從黑暗四周朝亮點聚攏，逆光的翅緣亮成細線，翅上的鱗粉在光裡飄散，像灰燼倒著往火裡飛。 | 摩擦聲一層一層加密，從四周往中央收。 |
| 4–6 | 鏡頭繼續極慢靠近，蛾群在亮點前越聚越密，翅影開始在光上閃動。 | 4.5 秒：近耳、方向模糊的人聲「……看著亮的地方。」，比摩擦聲更近、更輕。 |

<a id="vd-p0-00-4"></a>

### P0-00·4　看不見的平面

- **對應描述：**群蛾遮住光，亮點反而縮小
- **情緒節奏：**想靠近卻被擋住；光看得見，碰不到。整段越來越暗、越來越悶。
- **鏡頭：**鏡頭停住，不再推近。焦點先在遠處被遮住的亮點，3 秒時拉回眼前極近處，停在貼著那層看不見平面爬動的蛾上。
- **光：**亮點被蛾群一層層遮住，只剩翅間漏出的暖光隨翅膀閃爍，畫面整體一路變暗。貼在平面上的蛾被背後的漏光照出半透明的翅脈與細足。

| 秒 | 畫面 | 聲音與後製 |
| --- | --- | --- |
| 0–3 | 蛾群在亮點前疊成一團，亮點一點一點被遮小，漏出的光在翅間閃動，畫面越來越暗。 | 摩擦聲到最密，像整片乾紙在磨。 |
| 3–5 | 焦點拉回眼前：幾隻蛾停在一層看不見的平面上，像停在一片玻璃上，細足張開貼著平面慢慢爬，腹面朝向鏡頭；平面本身沒有任何反光或邊框。 | 4 秒：更輕的人聲「別先走。」，留住人的氣息與一點猶豫。 |
| 5–7 | 遠處的亮點縮成極小的一點，仍看得見；近處的蛾繼續爬，偶爾有一隻振翅又停下。 | 人聲之後只剩摩擦聲與很淺的呼吸。 |

### P0-00·5　一滴水

- **對應描述：**一滴水落在撐地的手背上
- **情緒節奏：**被一滴冷水從夢裡拉回。暖光消失，換成潮濕、低溫和身體的痛。
- **鏡頭：**前半維持夢裡的鏡位；水滴落下時焦點拉到畫面下緣的手背，接著視線慢慢抬起一點，停在起身前的主觀視點。全程不晃動、不旋轉。
- **光：**夢的暖光被翼緣遮掉後全黑。現實只有遠處設備指示燈的微弱光與水面反光，冷暖都很低；手背上的水珠映出一點設備光。
- **尾格：**P0-V01

| 秒 | 畫面 | 聲音與後製 |
| --- | --- | --- |
| 0–2 | 一片翼緣從畫面上方緩緩掃過，把最後一點暖光遮掉，畫面全黑。 | 摩擦聲開始變悶、變遠。 |
| 2–3.5 | 黑裡，一滴水從上方落下，打在畫面下緣撐地的手背上：水珠碎開，沿乾裂的手背滑下，手指微微一動。 | 2.3 秒：水滴打在皮膚上的一聲，乾淨、很近，是整段第一個現實的聲音。 |
| 3.5–5.5 | 滴落處擴出一圈水紋，接上手邊淺水的水紋；水面慢慢反出一點光，看得見濕滑踏台的邊。 | 摩擦聲轉成管內回流與遠處水泵的低頻；夢裡的人聲不再出現。 |
| 5.5–8 | 手掌壓實濕滑踏台，視線緩緩抬起一點，近處低矮的管頂與一顆微弱的設備燈進入畫面，停在起身前的主觀視點。 | 滴水、回流與水泵穩定下來，接 P0-01 的環境聲。 |

### P0-01·1　撐起

- **對應描述：**她先收起受傷的膝蓋，再以手肘撐起
- **情緒節奏：**吃力而謹慎。身體受了傷，每一下都先試過才用力。
- **鏡頭：**約 28mm 主觀視線，由身體帶動上升：升一點、停半拍、再升，有重量與停頓，不是平滑的升降；地平線全程水平，最後停在面對同一道維修柵門的視點，最後一格停穩，接回自由查看。
- **光：**現在的暖黑；光源只有遠處設備指示燈與水面反光。視點升高時，水面反光在畫面下緣移動、變細。

| 秒 | 畫面 | 聲音與後製 |
| --- | --- | --- |
| 0–1 | 撐地的手先壓緊踏台，指節用力，手肘貼地；畫面下緣受傷的膝蓋慢慢收回，破損的牛仔褲與乾暗的血布條一閃而過。 | 膝蓋擦過濕水泥的細響，布料拖過淺水。 |
| 1–2.5 | 以手肘撐起，視點分兩段升高：升一點、停半拍、再升；管頂與水線跟著慢慢下移，手留在畫面下緣，手腕微微發抖。 | 1.6 秒：手掌在濕踏台上滑了一下又抓穩的水聲。 |
| 2.5–3.5 | 動作停下，視點停穩在同一道維修柵門前，畫面靜止；手仍撐在下緣。 | 動作停穩後才進 OS「……先別站。等看得見。」，不壓在動作上。 |

### P1-01·2　上鋪床沿的包紮

- **對應描述：**記憶裡是一張上鋪的床沿
- **情緒節奏：**被照顧的安心。很小、很日常的一刻，最後那一下收緊是整段的重點。
- **鏡頭：**她坐在上鋪床沿低頭看自己的手腕；約 35mm，幾乎不動，只有極輕微的呼吸起伏。焦點從床沿移到手腕，再停在布結上，不推、不搖。構圖只到手肘。
- **光：**唯一光源是走廊從門縫漏進來的一道斜光，落在床沿與兩個人的手上；手與布的邊緣有柔和的亮邊，其餘沉在暖褐的暗部。

| 秒 | 畫面 | 聲音與後製 |
| --- | --- | --- |
| 0–1 | 上鋪床沿的鐵管與皺床單，一道走廊漏進來的斜光橫過床沿，灰塵在光裡慢慢飄。 | 很靜，沒有聲音。 |
| 1–2 | 焦點從床沿移到擱在膝上的手腕：一道擦傷，邊緣微紅，還沒結痂。 | — |
| 2–3.5 | 另一雙手從右側入鏡，米色、過長的袖口蓋到指節；捏住一條乾布的邊用力一撕，撕下一長條，布纖維在光裡散開；布條纏上她的手腕，繞兩圈。 | 2.2 秒：布被撕開的一聲，乾、短、很近。 |
| 3.5–5 | 打一個結，再打第二個，把尾巴拉到只剩一指寬，最後一拉，收緊；她的手指跟著輕輕一縮。畫面停在那個短尾雙結上。 | 3.5 秒：無聲字幕「這樣洗澡不會鬆。」；5 秒畫面結束時接回管線層的滴水。 |
