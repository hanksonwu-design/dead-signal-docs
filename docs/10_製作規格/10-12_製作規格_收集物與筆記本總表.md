# 收集物、背包與筆記本總表

> 本表供企劃、程式、美術與 UI 盤點。依現行劇本整理，沒有新增掉落物或道具系統。表內含全劇揭露，不直接作為玩家開場可見清單。

正式行為以[共用附錄](../09_劇本/09-15_正式劇本_共用附錄.md#doc-0404)及各幕製作規格為準；逐項來源與全場景物件見[劇情節點與場景道具總表](../08_製作管理/08-13_劇情節點與場景道具總表.md#inventory-props)。下列證據與索引是該表的製作查閱整理；原件內容或取得條件更動時須一併核對本表。

## 一、東西收在哪裡

| 收錄位置／類型 | 放入的內容 | 取得與使用方式 |
| --- | --- | --- |
| 背包／指定可攜帶實物 | 開場求生用品形象、原劇本指定跨房使用的記憶卡 | 只有明訂可帶走的物件才列可攜帶；不把所有近看物件變成物品欄 |
| 筆記本「觀察」 | 文件摘記、照片所見、血字、痕跡、人物與設備狀態 | 實際查看才記錄已知內容；原件通常留現場 |
| 筆記本「調查」 | 已取得的證據來源、初步關聯、正式推理結果 | 與觀察共用來源；親手比對才產生結論，不另發同件物品 |
| 筆記本「路線」 | 已查明的通路、K0／K1／K2 索引、維修方向 | 只記已知路線；開門另驗供電、憑證與現場操作 |
| 筆記本「訊號索引」 | #1–#15 的名稱、來源設備及已知摘要 | 只作索引；播放回現場設備。#7 是資料、#14 是文字 |
| 相關紀錄頁 | F1–F5、支線文件、人物註記、已見回想 | 附於原觀察／調查紀錄，不新增重複收藏分頁 |
| 現場設備／選單收藏 | 終端快取、冷備份原件、歌曲收藏與片尾解鎖 | 與主觀筆記分開；只有可移交設備原件能供終幕外送 |
