# 上部場 18：校正走廊（小說版・富江風格）

以伊藤潤二《富江》的風格試寫的版本，與[小說版第四稿](上部場18_校正走廊_小說版第四稿.md)並存：語氣平淡，怪異的身體細節看得很仔細，同一個東西一再複製，身體不聽自己的話，結尾停在一個畫面上。敘述的人不是冷靜，是嚇到只剩下平淡。以這一版為底、穿插現場資料的版本見[紀錄夾敘式](../../11_小說/11-卷05-01_校正走廊.md)。

這一版有兩處超出上部細綱（已改寫成[小說大綱](../../11_小說/11-01_小說大綱_卷一至卷五.md)）場 18：布簾凹出一張帶笑的臉（細綱只有額頭靠上來，小花不現身），以及她好像幫那雙手剪過指甲。要帶回電影，得先改細綱。

---

門牌旁邊的漆上刻著三個字：小黑屋。

筆畫的溝裡卡著一些白白的、半月形的碎片。我湊近去看，看了很久，才敢承認那是指甲。一片，兩片，三片，四片。我數到四就不數了。「屋」的最後一橫出了界，一路拖到門框上，那裡好像還卡著一片，我沒有再看。

推門的時候，我的手往門把下面壓了一下，門就開了。

我站在門口，看著自己的手。剛才那一下，是誰教我的？

門一關，那個一直跟著我的嗡嗡聲就停了。安靜得很突然，安靜到我開始聽見一些平常聽不見的東西：自己吞口水的聲音，衣服摩擦的聲音，還有一種很細、很乾的聲音，像什麼東西在刮板子。

我屏住氣聽。沒有了。也許從來就沒有。

吸音板封住了走廊兩邊所有的舊門洞。板子上全是洞，一個挨著一個，大小都差不多。我不知道為什麼，把左手的食指伸進其中一個。剛好塞滿。我把手指抽出來，又伸進旁邊那個。也剛好。

我把手指在褲子上擦，擦了很久，一直覺得沒擦乾淨。

只剩六扇門沒封，每扇門上有一格小窗，裡面是黑的。中間倒著一台推車，再過去一道布簾，最裡面一排監視螢幕還亮著，白光照得什麼都很平，像病房。

頭頂的舊門牌在晃。這裡沒有風。

我往前走一步，它就停了。停得很乾脆，好像有人伸手把它按住。

我不敢動了。

然後是呼吸。走廊那一頭的積水往兩邊分開，一段，一段，朝我這邊過來。水裡沒有腳，只有分開的水。

我躲到推車後面。膝蓋撞到地，痛得我差點叫出來，我把那一聲吞回去，嘴裡有血的味道。我的手在抖，我把兩隻手夾在膝蓋中間，還是在抖。

推車的鐵架中間夾著一片玻璃。那個東西停在推車另一邊，玻璃映出了它的肩膀。

肩膀被玻璃的接縫切成四片，對不齊。上面是一截衣領，領口一圈黃黃的汗漬。衣領裡沒有頭。

有一層殼。

灰黃色，半透明，有很細的直紋，從邊緣往裡捲，一圈一圈捲得很緊。我盯著那些直紋，越看越眼熟，眼熟到我想吐。那個紋路，跟我的指甲一樣。

不會吧。

它在呼吸。殼的邊緣收進去，放出來，收進去，放出來。

我的牙齒開始打顫。我用舌頭頂住，頂到舌頭發痠，還是在打顫。

殼停了。

它在聽。

我把照片拿出來。照片上的人在笑，臉被光吃掉了，只剩那個笑。很好看的笑。我每次看它都只看那個笑，從來沒有想過要看清楚那是誰。

拜託。拜託。

照片在我手裡抖得太厲害，那個笑抖成一片白。沒有用。

殼開了一點，朝我這邊。裡面還有一片殼，比較小，捲的方向也一樣。那片小殼裡面，好像還有一片更小的。一層一層，全都在呼吸，同時收，同時放。

我不想再看了，可是我閉不上眼睛。

推車側邊掛著一台控制器，螢幕下面寫著：核可關閉訊號。

然後我聽到很短的一聲，嗶。

我低頭。右手按在那個鍵上。

我不記得我有按。

玻璃上的肩膀淡掉了。心跳一下子變得很慢、很穩，穩得不像我的。走廊變得好清楚，清楚到每一個洞我都數得出來。最裡面某一扇門的小窗上，好像貼著一隻白白的手，五根手指張開，指甲很長。我的眼睛滑過去，沒有停。

我一直在看我的右手。它擱在控制器上，一動也不動。我叫它拿開，它過了一下才拿開。

「內控主管，已確認。」

廣播的女聲很有禮貌，很平，每個字都一樣重。

我抱住頭。誰？她在叫誰？這裡還有誰？

沒有人回答。迴音散掉了。

我開始數，數到二十一，就再也蹲不住了。我站起來往前走，腿一直發軟。經過左邊第三扇門，小窗是黑的。我回頭又看一次，還是黑的。

剛才那隻手呢？在哪一扇？

太暗了。我把發光棒塞進外套裡折斷，啪的一聲，比我想的還響。

最裡面的螢幕一台一台黑掉。

是我嗎？是剛剛那一聲嗎？

第二個從布簾那邊過來了。

推車在十步外。我的右手往那邊伸。我用左手抓住它，它還在往那邊掙，我抓到指甲都陷進自己的肉裡。

我躲進左邊第三扇門的門框，背貼著門，整個人在發抖。

對面的小窗映出那個肩膀。我憋住氣，開始數。

五。殼的邊緣在收。

十一。殼開了，裡面那片小的也開了。

十七。最裡面那片，最小的那片，開口對著我。它的邊緣上，有一個很小很小、彎彎的弧度。

二十三。那個弧度，像在笑。我一定是看錯了。

二十八。

叩、叩。

我背後的門，從裡面被敲了兩下。很輕，就在我的後腦勺。

眼前閃過一盞檯燈，燈罩上停著一隻蛾。燈下有一截太長的袖子，袖口底下的手指剛敲完桌子，指甲剪得很短，很乾淨。

是我剪的嗎？我好像幫誰剪過指甲。我想不起來是誰。

叩、叩。

我的右手又抬起來了，指節已經彎好，要敲回去。我用左手壓住它，左手是麻的，壓不住。我用整條手臂把它壓在胸口，它就在我胸口上，一下，一下，敲著我的骨頭。

我壓不住我自己的手。

殼停了。它在聽。

鼻血流下來，我用左手接住。沒有聲音。

門縫底下開始滲出粉。然後是蛾。

牠們的肚子一節一節的，上面長著很細的毛，粉從毛裡一直掉下來。牠們爬上我的鞋，爬進褲管，往我胸口的光爬。一隻停在我的上唇，停在血上，口器捲起來，又伸直，伸直，又捲起來。

牠在喝。

我哭出來了，沒有聲音，眼淚一直流。

更多的蛾從門縫湧出來，蓋住我，蓋住光，拍翅膀的聲音乾乾的，貼著我的耳朵。

我把發光棒放開。它滾出去，蛾跟著走，從我身上一片一片剝下來。嘴唇上那隻最後才走。

對面玻璃裡的肩膀沒有動。一秒，兩秒。我以為它要轉過來了。

玻璃空了。

很遠的地方，綠光被蓋住，熄了。

全黑。

黑暗裡，有東西在我右邊呼吸。涼涼的氣碰到我的臉頰，帶著一點點味道。很熟的味道。我想了很久，想到一個我很不想想到的答案：剪指甲的時候，那些碎屑的味道。

它停了。它還在嗎？我不知道。我什麼都不知道。

叩、叩。

比剛才更輕。

我張開嘴，只有氣：「……再等我一下。」

我在說什麼。我為什麼會說這句話。

我爬到布簾後面，手抖了好幾次，才把第二支發光棒折斷。我在筆記本上寫：這一次，停著也是一個能做的決定。

字歪成一團，「定」的最後一筆歪出了格子，一直往下拖。我看著那一筆，覺得好像在哪裡看過。我不敢想是在哪裡。

布簾鼓起來了。

布料慢慢往我這邊凹，凹出一個形狀。先是額頭，然後是鼻子，然後是閉著的眼睛。最後，在嘴的位置，布料往上彎出一個弧度。

一個笑。

我把照片拿出來。我不想拿的，可是我的手已經拿出來了。我把它舉到布簾前面，手抖得對不準，一下對到，一下又偏掉。

對到的那一下，兩個笑疊在一起。

我不敢再對第二次。
