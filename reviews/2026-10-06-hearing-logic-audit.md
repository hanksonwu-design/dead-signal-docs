# 聽覺判讀與怨靈遭遇邏輯複查

範圍：聲音／波形判讀的 10 個既有節點、各幕遊戲劇本、製作規格、共用玩法、圖像工單及網站標示。本次是文件規則與網站檢查，不是 Godot 遊戲實測。

## 已修正的矛盾

| 問題 | 修正與保留條件 |
| --- | --- |
| 正常側耳與真正察覺玩家的表現接近 | 正常巡行沿原方向檢查；失誤後才轉向最後發聲位置並啟動 2.2 秒補救。音量不直接代表發現或距離。 |
| R18 部分掩體可能被寫成安全復位點 | 區分當輪退避位置與失敗／讀檔的完整掩體復位點。N2 不覆寫安全點；未到 N3 者回已到達的 N1，舊檔缺乏到達紀錄則回 N0。 |
| R18 完成與換房條件有循環依賴風險，R19 初始安全點未明列 | N3→N4 移動不先要求完成旗標，親自抵達 N4 才保存段 A 並解除巡行，玩家再手動開門。進 R19 先實際停在門鉸後牆角並登記安全點，再移至關門操作位。 |
| R19 有「關太快」懲罰，但輸入只有固定時間長按 | 撤除無法對應操作的懲罰。2.4 秒慢關門、至少 3.2 秒前兆與確認後 5.2 秒屏息分開；早按不預耗氣，重試保留關門成果。 |
| R19 門邊被描述成完整掩體，卻仍要求屏息 | 門邊是部分聲音遮蔽，門鉸後牆角才可換氣與操作原控制器。提早鬆手須退回重試，不以分段屏息拼接成功；抹除仍須手動關門。 |
| R20 清除怨靈後，潛行完成鍵可能永遠無法成立 | 躲過完整側耳並親自返回控制台才完成；權限抹除則同次寫入抹除與段 C 完成。聲軌、F3、本地憑證仍須各自完成。 |
| R20 安全位置與必要試聽條件不完整 | 入房先到既有桌側實心擋板安全位，桌下仍需屏息；原控制器可在安全側使用。不必故意播錯 B／C 才能遇到原巡行。完成後安全查閱，不等待已終止的安全窗。 |
| 閱讀、回看或重播可能讓已完成的巡行重新出現 | 未完成者返回操作才給完整前兆；已完成／抹除者不因 B／C、H-08、回訪或讀檔重生。未抹除者後續沿原平行工作梯移動，不重啟玩家側追逐。 |
| 電子聲受抑制，卻仍有擴音器吸氣及未定義的延遲播放 | R18 振膜改為通風壓差的視覺變化，停用舊吸氣音槽。R20 設備僅在允許窗口實際試聽，危險狀態停播且清除待播回音；靜默不代表斷電。 |
| 退避、閱讀與時間輔助可能刷新時限或讓屏息無法通過 | 補救判定接受輸入的時點，退回仍走實際路程；不補回屏息、不把退避當通過。完整閱讀與真正暫停分開處理，輔助不延長必須屏息的敵人停留。 |

## 一致性

- 第四幕三段是各自的本地遭遇；U2b／U5 沿原 UD 控制器，其他節點只借用聽覺提示，不新增跨房追兵。
- 48 個主節點、56 條動線、72 個次場景、523 列圖像工單、224 個熱點綁定及 342 段場次維持不變。工單數不變不代表美術、音效及 UI 沒有新增工時。
- 網站共 210 個關鍵標示；R19 標在確認屏息段落，R25 喇叭時序歸解謎，不誤標為額外怨靈。
- 共用玩法、技術參考、劇情節點總表、scene-flow、網站文件資料及閱讀／3D 標示已由正式來源重建。

以下三輪依序執行，每輪先讀取現行文件、找出問題、修正正式來源並同步衍生文件，再跑全套測試；不是將同一輪測試重跑三次。

| 輪次 | 檢查與修正 | 當輪驗證 |
| --- | --- | --- |
| 第一輪：觸發與完成 | breath_required 漏列 R18 N2，補回部分掩體的側耳屏息需求。補救原本一律回 LISTENING，改成保存並續接 TELEGRAPH／CROSSING／LISTENING 原剩餘時間；R19 仍是退牆角重新確認。補足移動中警戒凍結前向位移、屏息餘量不足時續退完整掩體。 | Node 118/118；正式來源同步通過 |
| 第二輪：中斷與保存 | 消除「巡行中不寫檔」與完整掩體存檔衝突，改由安全到達事件存檔。補明失焦／斷線後的恢復確認、長按重新確認與選單輸入不穿透。抹除及受擊結果只結算一次，重複回呼、舊畫面或讀檔不重扣、不重加空白名冊。 | Node 121/121；正式來源同步通過 |

## 待實機驗證

Godot 原型仍須逐一測試 2.2 秒補救輸入邊界、長退程、屏息早放／耗盡、零穩定度抹除、兩種完成路線、舊存檔、暫停／失焦及無聲／低動態模式。需由實際遊玩確認掩體辨識、反應窗公平性、聲音包絡與畫面同步、緊張及喘息節奏；文件檢查不能證明恐怖效果已達標。

L05／V07 點陣概念圖本次未重繪；圖說已明列不適用內容與現行依據，正式姿態、樓層字樣、來源標籤及聽覺帶合成仍依原圖像工單製作。這不是已完成美術交付。
