# 對白口語與台灣語序潤修

日期：2026-10-19

本輪依對白自然度分析，修改十個有聲落點。讓主角回應眼前處境、小花清楚質問共同經歷，管理者錄音維持原有公事語氣。角色國籍與母語仍依原設定留白。

| 落點 | 原句 | 修訂句 |
| --- | --- | --- |
| P0-03a | 這裡傳不出去。沿維修道上去，找還能用的設備。 | 傳不出去……沿維修道上去，找找還有沒有能用的設備。 |
| R4b-02 | 他們只是接手了記錄的人。 | 連這本簿子，都拿來管人了。 |
| R6-01 | 他們下班後沒有地方去。所以這裡也算下班。 | 下了班，也只能待在這裡。 |
| ACT2-01／已讀信仰來源 | 他們把人分成工作、生活、信仰。最後每一欄都能換成一個號碼。 | 工作、生活，連求個平安都要照他們的規矩。人就剩下一個編號。 |
| ACT2-01／未讀信仰來源 | 他們把工作和生活分成一欄一欄。最後每一欄都能換成一個號碼。 | 上班、下班，都被他們排好了。人就剩下一個編號。 |
| R23／身體 OS | 視野又黑了。 | 眼前又黑了。 |
| R24／身體 OS | 先坐到不暈。 | 先坐著……頭好暈。 |
| U3-01／完整 LM-03 | 小花想要一張修理桌。我答應過，出去後陪她找。 | 我答應過她……出去了，陪她找張修理桌。 |
| R32-09／小花現時質問 | 妳每一次都說出去。那我呢？ | 妳每次都說妳要出去。那我呢？ |
| R32-C1／主角現時回答 | 我陪妳走到這道門。不替妳決定出去。 | 我陪妳走到門口。要不要出去，妳自己決定。 |

正式正文、製作規格場景引句與配音逐字表已同步；修訂配音標為「口語修訂；待讀演」。共用附錄的角色、結局與字幕引句、縮寫小說及分類查閱副本一併對齊。R6-01 標題改為「下了班，也只能待在這裡」，節點編號與錨點保留。

第二幕仍須已讀 E1-10 或實際解讀 E2-09，才使用含信仰的版本；兩條互斥，末句「最後那一欄，是拿來做什麼的？」保留。「人就剩下一個編號」是對已見人員管制的感受，小花的去向與未知身分仍待查證。

U3 現時回想仍在兩項特徵關聯後播放；歷史記憶「出去以後，找個能放修理桌的地方。」「好，我陪妳找。」保留。R31 責任承認、R32 揭露順序、C 線主角回返與小花自行決定去留的立場皆保留。
