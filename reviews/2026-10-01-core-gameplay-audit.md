日期：2026-10-01

本輪修改遊戲劇本、製作規格、共用設定與衍生查閱文件；不是遊戲引擎實作或正式美術交付。文件檢查於提交前完成；提交與遠端同步狀態以 Git 紀錄為準。

## 完成範圍

- 共用附錄增加八幕玩法遞進，以及原 48 個節點逐一對應的觀察、判斷、操作、回饋和退路；總目錄、八份製作規格及場景道具總表均可連到同一來源，不另建通關條件副本。
- 照片補 P1 初見、R1 安全位置使用、R19–R21 鎖定差異、R26 後清晰回收。只有成功安定才計次；補零次使用、冷卻、話術後一次加倍、零穩定度與續存規格。
- R1 #1 鈴聲引導注意、#2 重置候坐與 #3 叫號完成分開。前兩項為可略過的有效測試，少於 5 點不啟動；必要叫號保留不足額備援。
- 留光明定 P1／R8／R12／U4 四個位置，全輪仍最多三槽；補取消、重按、讀檔、反向鏡位與零槽路線。
- 恐慌 3 的錯置殘影落在 R17／R21，來源分別是已見 R3 床架及 R19 椅腳；不帶人形、文字或新證據，實景與原件可查證。
- 同步角色、世界觀、訊號、資源、美術方向、原型驗收、資產預算、製作參考、道具總表、精簡版小說及網站資料。

## 發現並修正

| 原落差／風險 | 修正 |
| --- | --- |
| 訊號總表稱鈴聲、重置有效，R1 正文卻一律激怒 | 統一為兩種局部有效回應，只有叫號才讓路；限制為本機效果，不外推到所有怨靈 |
| R1 製作包與原型回訪步驟仍寫安息 | 改為等待循環完成，保留原通路狀態，不給安息獎勵、不復活五人 |
| 照片可被解讀成開關頁面就增加清晰度 | 成功安定才計次；平靜、冷卻、鎖定及零穩定度只閱讀。第五幕兩種阿彪處置皆完成揭露，不新增照片門票 |
| 話術後「加倍一次」未說明作用於哪次冷卻 | 作用於下次成功照片使用，不延長現有冷卻、不倍增；保存待用標記與剩餘時間 |
| 固定留光卻在七窗段寫成隨身光源 | M1 改固定窗位感知顯影，不取用留光槽；R1／R4b 移除隨身發光棒假設 |
| U4 可能因留光用盡無法驗證回返 | 主線仍親繫本地單結布標、核缺角與焊疤；留光只補充辨路 |
| 高恐慌假訊號沒有出處，可能搶先透露或偽造線索 | 兩例各限定已見來源、位置與退出條件；閱讀、調查板不受遮罩干擾，R21 揭露後不補播 |
