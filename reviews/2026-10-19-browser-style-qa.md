# 企劃文件瀏覽器視覺更新驗收

日期：2026-10-19

以 UI 美術圖集「被塗改的紀錄，仍留下壓痕」為方向，更新首頁、分類導覽、搜尋、文件卡片／清單及閱讀頁。灰黑外殼配合錯層窗格、定位角、裝訂邊與灰米紙面；內文區維持乾淨背景。

## 操作確認

- 桌機實際開啟文件分類、卡片及清單，搜尋 UI 美術圖集成功。
- 圖集的原圖與製作註記正常呈現；自動章節導覽預設收合，選章後收合並移動至目標標題，確認標題聚焦且位於 sticky 工具列下方。
- 390px、320px 手機首頁沒有整頁橫向溢出，長分類名稱可容納。
- 手機分類收起時不可聚焦；開啟時焦點移入分類，背景主內容不可操作，選取分類後焦點回到選單按鈕。
- 320px 收集物總表在表格容器內橫向捲動，表格最小寬度仍為 760px。
- 必要物件維持粉色 #ffb4a8，功能物件維持青色 #8fd7cf，均增加深色底襯以適應紙面閱讀區。
- 劇本關鍵標示開關可隱藏／顯示；保留共用標記色，標示加上深色底襯。
- 閱讀器進出保留焦點還原；手機尺寸測試完成後已清除瀏覽器尺寸覆寫。
